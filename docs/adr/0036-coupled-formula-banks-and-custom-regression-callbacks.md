# ADR 0036: Coupled Formula Banks and Custom Regression Callbacks

## Status
Accepted (extends [ADR 0016](0016-ode-multi-solver-comparative-overlays.md), [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), and [ADR 0035](0035-compiled-ast-bytecode-and-unified-formula-sandboxes.md))

## Context
1. **Multi-Equation Parameter Duplication**: Dynamical sandboxes authoring coupled vector fields (`OdeSolverTool` `(y', v')`, `AttractorPlotter` `(dx/dt, dy/dt, dz/dt)`) cannot instantiate independent `ParameterSliderBank`s per equation without duplicating shared free parameters (`a, b, c`) or misaligning `CompiledExpr` parameter indices during transient syntax edits.
2. **Background Worker & Hamiltonian Formula Streaming**: Interactive chaos (`BifurcationDiagram`, `AttractorPlotter`, `FractalViewer`) and `UnifiedModel` quantum (`WaveUnified`) tools lacked zero-allocation `CompiledExpr` worker payloads, while `OdeSolverTool` relied on recursive `Expr` evaluation for scalar-only custom equations.
3. **Quadrature, Surface Domain, Loss Metric, and Regression Caps**: `RiemannIntegrationTool` did not expose `ClenshawCurtis` adaptive quadrature or error estimates; `CustomSurfaceSandbox` fixed `[u, v]` bounds; `LossLandscapeTool` supported only preset linear targets with MSE; and `egui_plot` capped Levenberg-Marquardt nonlinear fits at 5 parameters without custom formula callbacks.

## Decision
1. **Synchronized `CoupledExpressionBank`**: Introduce `CoupledExpressionBank` in `math_explorer_gui/src/framework/math_input/coupled.rs` to deduplicate union free parameters (up to `MAX_SYNTHESIZED_PARAMS = 6`) into one shared `ParameterSliderBank`, compile all equations against aligned parameter indices via `CompiledExpr::compile_with_vars_and_params`, and retain the last valid bytecode slice across transient syntax or parameter-cap errors.
2. **Chaos, Quantum, and Coupled ODE `CompiledExpr` Pipelines**: Enable custom 1D maps `x_{n+1} = f(r, x)` on `BifurcationDiagram`, stream `Arc`-shared `CompiledFlowJob` (3D RK4) and `CompiledFractalJob` (`Complex64` progressive `8 -> 4 -> 2 -> 1` escape passes) to background workers without UI stalls, add opt-in `UnifiedFormulaSpec` / `CompiledFormulaPayload` hooks on `UnifiedModel` for custom 1D `V(x)` Hamiltonians in `WaveUnified`, and upgrade `OdeSolverTool` + `comparison.rs` to integrate and compare scalar and coupled `(y, v)` `CompiledExpr` systems across RK4, Heun, and Euler.
3. **Clenshaw-Curtis Quadrature, Parametric Domain Bounds, and Robust Losses**: Expose `ClenshawCurtis` alongside `Trapezoidal` partitions with Richardson and spectral error estimates in `RiemannIntegrationTool`, add validated ordered `[u_min, u_max]` and `[v_min, v_max]` domain bounds across `SurfaceViewer`, `CurvatureHeatmap`, and `.obj` exports, and add formula/table `(x, y)` target datasets plus MSE, MAE, and Huber (`delta`) objectives to `LossLandscapeTool`.
4. **Decoupled 6-Parameter Levenberg-Marquardt & Custom Fit Registry**: Generalize `egui_plot/src/fit/` (`MAX_FIT_PARAMS = 6`) with central finite-difference Jacobians (`levenberg_marquardt_numeric`) and a thread-safe `CustomFitCallback` / `CustomFitEvaluator` registry in `egui_plot` so `math_explorer_gui/src/framework/fit_bridge.rs` compiles user formulas via `CompiledExpr` while keeping `egui_plot/Cargo.toml` completely independent of `math_commons`.

## Consequences
- **Positive**: Preserves zero heap allocations under `VerifiedAllocator` in inner evaluation, ODE stepping, complex escape, loss surface, and curve-fit evaluation loops while preventing false `FiniteStateGuard` rollbacks during live formula typing.
- **Positive**: Persists custom equations, shared parameter maps, quadrature modes, loss objectives, and surface domain bounds in `#[serde(deny_unknown_fields)]` JSON presets and `#state=` URLs well below the 4,096-byte decoded cap without modifying `crates/unified_verification/api_baseline.json` or `egui_plot/Cargo.toml`.
