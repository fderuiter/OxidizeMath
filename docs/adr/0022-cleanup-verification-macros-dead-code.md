# ADR 0022: Remove Unreferenced Empirical Verification Macro, Dead-Code Suppressions, and Unread Epsilon Field

## Status
Accepted

## Context
1. `crates/pure_math/src/theory_macro.rs` exported `empirical_verification!`, which had zero callers across the workspace and ignored its `$obs` parameter, while `crates/unified_verification/src/report.rs` and `crates/oxidize_core/src/ast_visitor.rs` retained dead string checks for `empirical_verification`.
2. `theory_verification!` in `crates/pure_math/src/theory_macro.rs` emitted `#[allow(dead_code)]` on every generated constant, evading `DeadCodeVisitor` in `crates/unified_verification/src/policy_audit.rs` and masking five unreferenced constants (`TARGET_CAP` in `crates/domain_applied/src/applied/battery_degradation/mod.rs`, and `TEST` in `crates/domain_biology/src/biology/mod.rs`, `crates/domain_climate/src/climate/mod.rs`, `crates/domain_epidemiology/src/epidemiology/mod.rs`, and `crates/pure_math/src/pure_math/mod.rs`), contradicting ADR 0016 and ADR 0019.
3. `theory_verification!` required a top-level `epsilon` field across all 29 callers in six workspace crates (`pure_math`, `domain_applied`, `domain_biology`, `domain_climate`, `domain_epidemiology`, and `domain_physics`), even though `$epsilon` was never expanded inside the macro body and callers already specified tolerances explicitly in `assert_relative_eq!` assertions.

## Decision
1. Deleted the unreferenced `empirical_verification!` macro from `crates/pure_math/src/theory_macro.rs`, leaving `theory_verification!` and `stochastic_signature_verification!` as the active verification macros.
2. Removed dead checks for `empirical_verification` from `crates/unified_verification/src/report.rs` and `crates/oxidize_core/src/ast_visitor.rs`.
3. Removed `#[allow(dead_code)]` from constants generated by `theory_verification!` in `crates/pure_math/src/theory_macro.rs` so `rustc` enforces usage checks directly.
4. Deleted the five unused verification constants (`TARGET_CAP` in `battery_degradation` and `TEST` in `biology`, `climate`, `epidemiology`, and `pure_math`).
5. Removed the unread `epsilon` field from `theory_verification!` and from all 29 caller invocations across `pure_math`, `domain_applied`, `domain_biology`, `domain_climate`, `domain_epidemiology`, and `domain_physics`, while preserving all `assert_relative_eq!` assertions and tolerances inside `test` blocks.

## Consequences
- Eliminates dead macro definitions, dead verification string branches, and hidden `#[allow(dead_code)]` attributes in macro expansions.
- Ensures `rustc` immediately flags unused constants declared in `theory_verification!` blocks without requiring `verification_whitelist.toml` bypasses.
- Simplifies `theory_verification!` invocations to `module`, `constants`, and `test` while keeping traceability registration, assertion counts, WASM coverage checks, and public APIs unchanged.
