# ADR 0032: Replicator Step Validation and WebAssembly Panic-Quarantine Bridge

## Status
Accepted

## Context
Browser sessions compiled under `[profile.release]` (`panic = "abort"` and `overflow-checks = true`) exhibited three coupled reliability hazards across `crates/domain_applied`, `crates/diagnostics`, and `math_explorer_gui`:
1. **Unchecked Step Count Allocation in Replicator Dynamics**: `ReplicatorDynamics::simulate` and `ReplicatorDynamics::simulate_with_strategy` in `crates/domain_applied/src/applied/game_theory/evolutionary/replicator.rs` computed `let steps = (time_horizon / dt).ceil() as usize; Vec::with_capacity(steps + 1)` without validating `dt > 0.0`, `time_horizon > 0.0`, finiteness, or a bounded step ceiling. Passing `dt <= 0.0` (e.g., `0.0 / 0.0` or `20.0 / 0.0 = +inf` saturating to `usize::MAX`) triggered a fatal `steps + 1` arithmetic overflow or aborted WebAssembly memory allocation, and `ReplicatorPresetConfig::validate` in `math_explorer_gui/src/presets.rs` accepted `dt = 0.0`.
2. **Post-Boot Frozen Canvas on WebAssembly Traps**: `diagnostics::init_panic_hook` in `crates/diagnostics/src/lib.rs` emitted `Severity::Fatal` events only to the in-process `DiagnosticBus` while `math_explorer_gui/src/main.rs` dropped `eframe::WebRunner` after `runner.start` resolved and `math_explorer_gui/reload.js` gated global `error` and `unhandledrejection` listeners on `isBootPending()`. Any post-boot `RuntimeError: unreachable` trap froze `#the_canvas_id` silently.
3. **Poisoned Startup State Crash Loops and Misclassification**: `math_explorer_gui/src/app/theme.rs` restored `localStorage["app"]` unconditionally on startup, while `reload.js` omitted `WebAssembly.RuntimeError` from `classifyError` and mislabeled startup traps as `'network'` errors even when all bundle assets returned HTTP 200.

## Decision
1. **Fallible Bounded Simulation Grid in `ReplicatorDynamics`**: Update `ReplicatorDynamics::simulate` and `ReplicatorDynamics::simulate_with_strategy` to return `Result<Vec<(f64, DVector<f64>)>, GameTheoryError>`, rejecting non-finite or non-positive `dt` and `time_horizon`, non-finite or negative initial population entries, and step counts exceeding `200_000` (using `checked_add(1)` before `Vec::with_capacity`). Mirror these checks in `ReplicatorPresetConfig::validate` via `checked_ode_step_count` and propagate errors cleanly in `ReplicatorDynamicsTool::try_load_state` and `run_simulation`.
2. **Session-Long `WebRunner` and Synchronous Fatal Panic Bridge**: Retain `eframe::WebRunner` in a session-scoped `thread_local!` in `math_explorer_gui/src/wasm_crash_bridge.rs` and subscribe to `diagnostics::global_bus()` so `Severity::Fatal` panic messages and normalized forward-slash `file:line:column` source locations are forwarded synchronously to `window.__mathExplorerBoot.reportFatalPanic` before WebAssembly executes `unreachable`.
3. **Persistent Runtime Error Category, First-Frame Boot Sentinel, and Safe Mode Quarantine**: Split the browser startup/recovery shell into deferred external scripts (`recovery.js`, `reload.js`, `bootstrap.js`, `initializer.js`) all `<= 500` lines under strict `'self'` CSP. Keep global `error` and `unhandledrejection` listeners active post-boot, classify WebAssembly traps under `data-error-category="runtime"`, record a boot sentinel cleared only after Frame 1 renders in `MathExplorerApp::update`, automatically quarantine `localStorage["app"]` on the load following an aborted startup while preserving validated `html[data-theme]`, and expose manual workspace reset and quarantined-state download controls on `#error_container` and `#safe_mode_banner`.

## Consequences
- **Positive**: Invalid `dt <= 0.0` or overflowing step counts return `Err(GameTheoryError::InvalidParameter)` deterministically without panicking; post-boot WebAssembly traps and unhandled rejections surface diagnostic details in `#error_container` with assertive ARIA alerts; poisoned `localStorage["app"]` crash loops self-heal on reload while preserving theme preferences and offering offline backup export.
- **Neutral**: `crates/unified_verification/api_baseline.json` is regenerated to record the fallible `Result<Vec<(f64, DVector<f64>)>, GameTheoryError>` signatures on `ReplicatorDynamics::simulate` and `simulate_with_strategy`, and `[profile.release]` retains `panic = "abort"` within the 3 MB compressed `.wasm` budget.
