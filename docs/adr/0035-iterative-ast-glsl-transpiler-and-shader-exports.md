# ADR 0035: Iterative AST-to-GLSL Transpiler, WCAG Shader Colormaps, and Analytical WebGL2 / Shadertoy Fragment Shader Exports

## Status
Accepted (extends [ADR 0017](0017-native-ast-expression-parser-and-live-input.md), [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), [ADR 0026](0026-bounded-ast-height-and-iterative-traversal.md), [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md), and [ADR 0035](0035-compiled-ast-bytecode-and-unified-formula-sandboxes.md))

## Context
OxidizeMath provides interactive 2D mathematical field visualizers—including escape-time fractals (`FractalViewer`), conformal complex mappings (`ComplexMappingTool`), and linear potential-flow superpositions (`PotentialFlowTool`)—alongside tabular (`CSV`, `JSON`) and raster/vector (`PNG`, `SVG`, `GIF`) exports ([ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md)). However, researchers, educators, and shader artists lacked a way to export live analytical field configurations or custom AST formulas (`w = f(z)`) as standalone, zero-dependency GPU fragment shaders for WebGL2 (`#version 300 es`) or Shadertoy (`mainImage`):
1. **Bounded Iterative AST Traversal**: Recursive AST code generation risks stack exhaustion on adversarial or programmatically constructed trees ([ADR 0026](0026-bounded-ast-height-and-iterative-traversal.md)) and must preserve exact operator precedence, unary-vs-power binding (`-3^2 = -(3^2)`), IEEE-754 float literal formatting (`2.0`), GLSL identifier hygiene, and principal branch cuts (`cln`, `cpow`, `csqrt`) across all `20` [`Func`](../../crates/math_commons/src/ast/expr.rs) variants (including multi-arity `min`, `max`, `clamp`, `atan2` and piecewise `step`, `rect`).
2. **Perceptual & WCAG 2.2 Dark-Canvas Contrast Parity**: Exported shaders must reproduce CPU colormaps (`heatmap_color`, `cyclic_cosine_palette`) and bake the linear-light WCAG 2.2 `>= 3.0:1` dark-canvas luminance lift (`ensure_dark_canvas_contrast`, [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md)) when `ThemeMode::HighContrast` is active.
3. **Strict Offline CSP & Deferred Export Lifecycle**: Exported `.frag` downloads and clipboard copies must route through the deferred end-of-frame `ExportQueue` (`text/plain` local `Blob` downloads and system clipboard callbacks) with zero external network calls (`default-src 'self'`) and zero new Cargo dependencies.

## Decision
1. **Iterative Scalar & Complex AST-to-GLSL ES 3.00 Transpiler (`math_commons::ast::glsl`)**:
   - Implement [`crates/math_commons/src/ast/glsl.rs`](../../crates/math_commons/src/ast/glsl.rs) and [`crates/math_commons/src/ast/glsl_helpers.rs`](../../crates/math_commons/src/ast/glsl_helpers.rs) exposing `Expr::to_glsl_scalar`, `Expr::to_glsl_scalar_with_vars`, `Expr::to_glsl_complex`, `Expr::to_glsl_complex_with_vars`, `GlslError`, `format_glsl_float`, `GLSL_SCALAR_HELPERS`, and `GLSL_COMPLEX_HELPERS`.
   - Traverse `Expr` trees iteratively using an explicit `Vec<GlslFrame>` work stack bounded by `MAX_EVAL_DEPTH = 64`, rejecting deeper trees in `O(MAX_EVAL_DEPTH)` steps without Rust call-stack recursion.
   - Emit guarded IEEE-safe scalar (`glsl_div`, `glsl_pow`, `glsl_ln`, `glsl_log10`, `glsl_sqrt`, `glsl_step`, `glsl_rect`, `glsl_clamp`, `glsl_atan2`, clamped hyperbolic/inverse-trig) and complex `vec2` (`cmul`, `cdiv` with `dot(b, b) < 1e-12`, `carg`, `cln`, `clog10`, `cexp`, `cpow`, `csqrt`, `cabs`, and all `20` `Func` variants) helpers, while rejecting GLSL keywords, `gl_` prefixes, `__` infixes, and unbound variables.
2. **GLSL Colormap & WCAG Contrast Emitters (`math_commons::math_kernel::glsl_colormap`)**:
   - Add [`crates/math_commons/src/math_kernel/glsl_colormap.rs`](../../crates/math_commons/src/math_kernel/glsl_colormap.rs) providing `glsl_heatmap_color_fn`, `glsl_cyclic_cosine_palette_fn`, `glsl_ensure_dark_canvas_contrast_fn`, and `glsl_colormap_library` matching [`colormap.rs`](../../crates/math_commons/src/math_kernel/colormap.rs).
3. **Deferred `.frag` File & Clipboard Pipeline (`egui_plot` & `math_explorer_gui`)**:
   - Extend `infer_mime_type` in [`egui_plot/src/file_io.rs`](../../egui_plot/src/file_io.rs) to map `.frag` and `.glsl` extensions to `"text/plain"`.
   - Introduce `ShaderDialect` (`WebGl2Es300`, `Shadertoy`), `ExportCapabilities::shader` (`with_shader()`), `InteractiveTool::export_glsl_shader`, and `ExportFormat::{GlslWebGl2, GlslShadertoy}` across [`export_types.rs`](../../math_explorer_gui/src/framework/export_types.rs), [`export_queue.rs`](../../math_explorer_gui/src/framework/export_queue.rs), [`export_shader.rs`](../../math_explorer_gui/src/framework/export_shader.rs), and [`export_ui.rs`](../../math_explorer_gui/src/framework/export_ui.rs), announcing confirmations and diagnostics through `TwinSlotLiveRegion`.
4. **Analytical Tool Shader Emitters**:
   - Implement standalone WebGL2 (`#version 300 es`) and Shadertoy (`mainImage`) fragment shader emitters in [`fractals/shader.rs`](../../math_explorer_gui/src/tabs/chaos/fractals/shader.rs) (Mandelbrot/Julia smooth escape-time), [`complex_mapping/shader.rs`](../../math_explorer_gui/src/tabs/analysis/complex_mapping/shader.rs) (built-in and parameterized custom `w = f(z)` conformal domain coloring), and [`potential_flow/shader.rs`](../../math_explorer_gui/src/tabs/fluid_dynamics/potential_flow/shader.rs) (analytical superposition of `Uniform`, `Source`, `Sink`, `Vortex`, and `Doublet` elements capped at `MAX_SHADER_SINGULARITIES = 64`).

## Consequences
- **Positive**: Users can download `.frag` files or copy standalone WebGL2 and Shadertoy shaders in a single click from `FractalViewer`, `ComplexMappingTool`, and `PotentialFlowTool`, with zero external dependencies, zero hot-loop allocations, full `ThemeMode::HighContrast` WCAG `3.0:1` parity, and audited capability invariants across all `55` registered GUI tools.
- **Neutral**: Non-analytical discrete/ODE/statistical tools (`52` of `55`) keep `caps.shader == false` with an explicit `shader_disabled_reason` and omit shader buttons from their action bars to preserve toolbar clarity.
