# ADR 0035: Cross-Platform Playwright WASM Runner, Workspace Crate Discovery, and `Instant::now` Guardrails

## Status
Accepted (extends [ADR 0022](0022-wasm-clippy-guardrails.md), [ADR 0027](0027-enforce-workspace-clippy-lints.md), and [ADR 0033](0033-wasm32-browser-tests-and-playwright-ci-smoke-gate.md))

## Context
Local contributors, IDE test lenses (`rust-analyzer`, `cargo nextest`), non-POSIX hosts, and containerized environments encountered several failure modes when executing WebAssembly tests and browser smoke gates:
1. **Relative Non-Interpreter Cargo Runner & CWD-Relative `xtask` Overrides**: [`.cargo/config.toml`](../../.cargo/config.toml) configured `runner = "scripts/wasm_test_runner.py"` without an explicit `python3` launcher, failing on Windows, crate subdirectories, spaced checkout paths, and `0644` non-executable checkouts. Meanwhile, [`apps/xtask/src/gates.rs`](../../apps/xtask/src/gates.rs) overrode `CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER` from the caller's working directory and hardcoded only two crates (`oxidize_core` and `math_explorer_gui`).
2. **Incomplete `libtest` CLI Compatibility and Skipped Unit Targets**: [`scripts/wasm_test_runner.py`](../../scripts/wasm_test_runner.py) returned empty output on `--list`, ignored `--exact`, `--skip`, `--test-threads`, and multi-filter CLI arguments, exited zero when filters matched zero tests, and skipped standard `#[test]` unit binaries that did not export `WasmBindgenTestContext`.
3. **Excluded `egui_plot` WASM Coverage and Crate-Scoped `Instant::now` Lint**: [`crates/unified_verification/src/report.rs`](../../crates/unified_verification/src/report.rs) excluded `egui_plot` when computing `wasm_path_coverage_pct`, leaving browser file I/O and clipboard helpers in [`egui_plot/src/file_io.rs`](../../egui_plot/src/file_io.rs) and [`egui_plot/src/export.rs`](../../egui_plot/src/export.rs) unexercised in Chromium, while `std::time::Instant::now` was only banned in `math_explorer_gui` rather than root [`.clippy.toml`](../../.clippy.toml), allowing unguarded `Instant::now()` calls such as [`egui_plot/src/fit/tests.rs`](../../egui_plot/src/fit/tests.rs) to panic on `wasm32-unknown-unknown`.
4. **Manifest Version Drift, Unchecked `xtask setup` Tools, and Container Chromium Crashes**: Root [`Cargo.toml`](../../Cargo.toml) declared `wasm-bindgen = "0.2.100"` while [`Cargo.lock`](../../Cargo.lock) resolved `0.2.130`, [`apps/xtask/src/main.rs`](../../apps/xtask/src/main.rs) (`setup`) did not verify `wasm-bindgen`, `trunk`, `brotli`, or Playwright Chromium binaries, and [`scripts/wasm_test_runner.py`](../../scripts/wasm_test_runner.py) and [`scripts/playwright_smoke.py`](../../scripts/playwright_smoke.py) omitted `--no-sandbox` and `--disable-dev-shm-usage` for Linux containers.

## Decision
1. **Cross-Platform Python Launcher and Root-Anchored Workspace Discovery**:
   - Configure `target.wasm32-unknown-unknown.runner` in [`.cargo/config.toml`](../../.cargo/config.toml) as an explicit `["python3", "-u", "-c", ...]` launcher that locates `scripts/wasm_test_runner.py` across ancestor directories of `CARGO_MANIFEST_DIR`, `os.getcwd()`, and `sys.argv[1]` before executing it via `runpy.run_path`—working identically on Windows, macOS, Linux, subdirectories, spaced paths, and `0644` checkouts without nested `cargo` calls.
   - Implement pure-`std` workspace root resolution and `wasm32`-compatible crate discovery in [`crates/oxidize_core/src/workspace_wasm.rs`](../../crates/oxidize_core/src/workspace_wasm.rs) (re-exported by [`crates/oxidize_core/src/workspace.rs`](../../crates/oxidize_core/src/workspace.rs) and shared with [`apps/xtask/src/gates.rs`](../../apps/xtask/src/gates.rs) while keeping [`apps/xtask/Cargo.toml`](../../apps/xtask/Cargo.toml) dependency-free). Remove `CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER` overrides in `xtask test-wasm` and anchor all `cargo`, `trunk`, `verify_wasm_budget.sh`, and `playwright_smoke.py` commands to the workspace root across all 16 `wasm32`-compatible crates.
2. **Full `libtest` CLI Flag Support, Dual Unit/Browser Execution, and Container Chromium Flags**:
   - Upgrade [`scripts/wasm_test_runner.py`](../../scripts/wasm_test_runner.py) to parse `--list`, `--exact`, repeatable `--skip`, `--test-threads`, `--ignored`, `--include-ignored`, formatting/output flags, and multiple positional filters; inspect WASM export and `TestDesc` data sections to match crate-relative and crate-qualified module paths; execute both `#[wasm_bindgen_test]` browser suites and standard `#[test]` unit targets (`wasm-bindgen`-linked and standalone raw `.wasm` binaries) under production CSP headers; and exit non-zero whenever filters match zero tests.
   - Add `--no-sandbox` and `--disable-dev-shm-usage` to Chromium launch arguments in [`scripts/wasm_test_runner.py`](../../scripts/wasm_test_runner.py) and [`scripts/playwright_smoke.py`](../../scripts/playwright_smoke.py).
3. **`egui_plot` Browser Coverage, Workspace-Wide `Instant::now` Ban, and `xtask setup` Checks**:
   - Remove `"egui_plot"` from `collect_rs_files()` exclusions in [`crates/unified_verification/src/report.rs`](../../crates/unified_verification/src/report.rs) (preserving `egui_plot`'s `theory_verification!` exemption in `check_unverified_modules`), update [`crates/unified_verification/src/wasm_coverage.rs`](../../crates/unified_verification/src/wasm_coverage.rs), and add `#[wasm_bindgen_test]` suites in [`egui_plot/src/file_io_wasm_tests.rs`](../../egui_plot/src/file_io_wasm_tests.rs), [`egui_plot/src/export_wasm_tests.rs`](../../egui_plot/src/export_wasm_tests.rs), and [`egui_plot/src/export_modal_tests.rs`](../../egui_plot/src/export_modal_tests.rs).
   - Move `disallowed-methods` for `std::time::Instant::now` into root [`.clippy.toml`](../../.clippy.toml) and guard host-only timing blocks with `#[cfg(not(target_arch = "wasm32"))]` (including [`egui_plot/src/fit/tests.rs`](../../egui_plot/src/fit/tests.rs)).
   - Align `wasm-bindgen` (`0.2.130`), `wasm-bindgen-futures` (`0.4.80`), `wasm-bindgen-test` (`0.3.80`), `js-sys` (`0.3.107`), and `web-sys` (`0.3.107`) in [`Cargo.toml`](../../Cargo.toml) with [`Cargo.lock`](../../Cargo.lock), and validate `wasm-bindgen` `0.2.130`, `trunk`, `brotli`, and Playwright Chromium binaries in [`apps/xtask/src/setup.rs`](../../apps/xtask/src/setup.rs) during `xtask setup`.

## Consequences
- **Positive**: IDE test lenses, `cargo nextest`, member subdirectory invocations, spaced paths, `0644` checkouts, and containerized CI/devboxes run `wasm32-unknown-unknown` unit and browser tests reliably with zero silent filter passes or `/dev/shm` crashes.
- **Positive**: `xtask test-wasm`, `Verification_Certificate.json`, and workspace `wasm32` Clippy now cover `egui_plot` and every compatible workspace crate while preventing unguarded `Instant::now` panics.
- **Neutral**: Test-only dependencies (`wasm-bindgen-test`) remain scoped to `wasm32` `dev-dependencies`, preserving production web bundle sizes well under the `3,145,728`-byte budget in [`scripts/verify_wasm_budget.sh`](../../scripts/verify_wasm_budget.sh).
