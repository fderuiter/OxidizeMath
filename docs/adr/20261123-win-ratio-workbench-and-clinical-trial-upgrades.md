# ADR 20261123: Composite Win Ratio Workbench and Clinical Trial Biostatistics Upgrades

## Status
Accepted (extends [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), [ADR 0028](0028-finite-survival-time-and-total-order-kaplan-meier.md), [ADR 0035](0035-pharmacokinetics-adme-gui-workbench.md), [ADR 20261123](20261123-censored-win-ratio-u-statistics-and-weibull-power-sweeps.md), and [ADR 20261123](20261123-clinical-cohort-and-win-ratio-workbench.md))

## Context
[`crates/domain_applied/src/applied/win_ratio/`](../../crates/domain_applied/src/applied/win_ratio/mod.rs) implements a comprehensive prioritized composite endpoint suite—`WinRatioAnalysis`, `HigherIsBetter`, `LowerIsBetter`, `ThresholdComparator`, `UnmatchedPairing`, `MatchedPairing`, Pocock two-tier `WinLossCounts` (`calculate_sample_win_ratio`, `calculate_win_proportion`, `calculate_confidence_interval`, `calculate_significance_test_statistic`), `calculate_statistics` (`WinRatioStats`), `BivariateWeibullModel` + Clenshaw-Curtis `ProbabilityWinRatioContext`, and anthropometric `calculate_bmi`—requiring dedicated zero-allocation `WinRatioTool` coupling (`calculate_bmi` + `TTestIndependent` + `PR(c)` sweeps) alongside [`WinRatioWorkbenchTool`](../../math_explorer_gui/src/tabs/clinical_trials/win_ratio_workbench.rs) in [`math_explorer_gui/src/tabs/clinical_trials/`](../../math_explorer_gui/src/tabs/clinical_trials/mod.rs).

At the same time, existing biostatistical tools in `ClinicalTrialsTab` exhibited four workflow gaps:
1. [`SurvivalAnalysisTool`](../../math_explorer_gui/src/tabs/clinical_trials/survival/mod.rs) needed unified single-arm and multi-arm CSV/TSV parsing combining `try_estimate_hazard_ratio`, Mantel-Haenszel `log_rank_test`, `TimePoint` risk-set counts (`n_at_risk`, `n_events`, `n_censored`), and `.csv`/`.md`/`.svg` exports.
2. [`SampleSizeCalculatorTool`](../../math_explorer_gui/src/tabs/clinical_trials/sample_size/mod.rs) needed unified statistical power curves ($1 - \beta$ vs $N$ and required $N$ vs $1 - \beta$), `POWER_MILESTONES` protocol sizing tables, `.csv`/`.md` exports, and interactive `TTestIndependent` / `ChiSquare2x2` / `calculate_risk_metrics` cards.
3. [`RandomizationTool`](../../math_explorer_gui/src/tabs/clinical_trials/randomization.rs) and [`SimpsonParadoxLab`](../../math_explorer_gui/src/tabs/clinical_trials/simpson_paradox.rs) needed unified seeded `StratifiedRandomizer` schedules, per-patient `SubjectAllocationRecord` retention (`SUBJ-0001..`, `M-i`, `S-i`), cumulative arm-balance plots, and `.csv`/`.json` schedule downloads.
4. Clinical biostatisticians require 100% client-side, HIPAA-safe in-memory CSV/TSV file ingestion and report generation with bounded row counts (`MAX_ITERATIONS = 5,000`) and zero heap allocations in numeric hot paths under `VerifiedAllocator`.

## Decision
1. **Add `WinRatioTool` and Shared `ClinicalIoState` in `ClinicalTrialsTab`**:
   - Add [`math_explorer_gui/src/tabs/clinical_trials/composite_win_ratio/`](../../math_explorer_gui/src/tabs/clinical_trials/composite_win_ratio/mod.rs) (`ToolMetadata` `id: "WinRatioTool"`, `display_name: "Composite Win Ratio"`) alongside [`WinRatioWorkbenchTool`](../../math_explorer_gui/src/tabs/clinical_trials/win_ratio_workbench.rs) and [`WinRatioStressTesterTool`](../../math_explorer_gui/src/tabs/clinical_trials/win_ratio/mod.rs) with two `StarterPresetMetadata` cards (`win_ratio_composite_starter`, `win_ratio_weibull_prc_starter`), backed by [`clinical_io.rs`](../../math_explorer_gui/src/tabs/clinical_trials/clinical_io.rs) wrapping `web_io::spawn_open_file_dialog` and `web_io::spawn_save_as_file_dialog`.
   - Separate workspace buffer preparation (`prepare_workspace()`) from zero-allocation numerical evaluation (`evaluate_hot_path()`), running `WinRatioAnalysis`, per-tier cumulative attribution, Pocock `WinLossCounts`, secondary continuous `TTestIndependent` (`GroupData`), `calculate_bmi`, and Clenshaw-Curtis `ProbabilityWinRatioContext` (`calculate_win_probability`, `calculate_loss_probability`, `calculate_probability_win_ratio`) over `BivariateWeibullModel` horizons $c \in [c_{\min}, c_{\max}]$ ($c_{\min} > 0$ to avoid the $t^{\alpha - 1}$ singularity when $\alpha < 1$).
2. **Upgrade `SurvivalAnalysisTool`, `SampleSizeCalculatorTool`, and `RandomizationTool`**:
   - Upgrade [`survival/`](../../math_explorer_gui/src/tabs/clinical_trials/survival/mod.rs) to parse single-arm and multi-arm CSV/TSV cohorts up to `MAX_ITERATIONS`, preserve legacy `SurvivalState { input_text }` compatibility, compute two-arm `try_estimate_hazard_ratio` and `log_rank_test`, tabulate `TimePoint` risk sets, and export `.csv`, `.md`, and `.svg` artifacts.
   - Upgrade [`sample_size/`](../../math_explorer_gui/src/tabs/clinical_trials/sample_size/mod.rs) to combine analytical forward power curves (`calculate_power_means`, `calculate_power_proportions`) and required-$N$ curves with `POWER_MILESTONES` (`1 - \beta \in [0.50, 0.99]`), interactive hypothesis/risk cards, `ExportCapabilities::plot()`, and `.csv`/`.md` protocol sizing schedules without lint suppressions.
   - Add [`randomization_schedule.rs`](../../math_explorer_gui/src/tabs/clinical_trials/randomization_schedule.rs) (`SubjectAllocationRecord`) so `RandomizationTool` and `SimpsonParadoxLab` retain seeded per-patient IDs (`SUBJ-0001..`, `S0001..`, `M-i`, `S-i`), plot cumulative arm balance (`ExportCapabilities::plot()` across `Simple`, `Block`, and `Stratified`), and export `.csv` and `.json` schedules.

## Consequences
- **Positive**: Every clinical trial tool in `ClinicalTrialsTab` now advertises `ExportCapabilities::plot()`, passes offscreen PNG/SVG modal audits, executes 100% locally in memory on desktop and `wasm32-unknown-unknown`, and exposes end-to-end report/table downloads.
- **Positive**: `WinRatioTool::evaluate_hot_path` executes with zero heap allocations under `VerifiedEngine::run_verified`, and `MatchedPairing` enforces equal arm lengths prior to evaluation so domain panics are impossible from user input.
- **Neutral**: Global GUI registry contracts advance to `89` `InteractiveTool` entries (`69` plot-export tools, `12` non-figure tools, `86` non-shader tools) and `151` `StarterPresetMetadata` cards.
