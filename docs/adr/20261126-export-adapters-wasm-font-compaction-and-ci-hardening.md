# ADR 20261126: Typed Export Adapters, Build-Time WASM TrueType Compaction, and CI Pipeline Hardening

## Status

Accepted

## Context

Expanding dataset and figure export parity across all 111 interactive `MathExplorerApp` tools (`108` figure-and-dataset tools plus `3` `dataset_only()` analytical calculators) alongside the five-tier workspace migration surfaced five cross-cutting engineering constraints in continuous integration:

1. **Residual Core Dependency Drift**: Extracting `OxidizeRng` into `crates/00_foundation/math_rng` left an unreferenced `rand` dependency in `crates/01_core/oxidize_core/Cargo.toml` and a `rand::RngCore` import in `crates/01_core/oxidize_core/README.md`, failing unused-dependency detection.
2. **Cargo Subcommand Verification & Unpinned Tool Resolution in CI**: `.github/actions/ci-tool-cache/action.yml` verified cached binaries exclusively via `"$bin_path" --version`, causing Cargo subcommand plugins such as `cargo-llvm-cov` (`cargo-llvm-cov llvm-cov --version`) to fail with exit code 1, while `bnjbvr/cargo-machete` queried GitHub's unauthenticated `releases/latest` endpoint at runtime.
3. **Unoptimized `[profile.test]` Plateau Scan Overhead**: `egui_plot::poi::plateau::compact_slice` invoked `Option::and_then(T::chunk8)` closures, copied 128-byte chunk arrays, and executed 40 floating-point operations per 8 samples, pushing 200,000-point plateau compaction slightly past the `5ms` ceiling under `opt-level = 0` on Windows and macOS runners.
4. **WebAssembly Compressed Bundle Budget (`< 4 MB`)**: Adding typed table and primitive export adapters across 17 simulation tools pushed `math_explorer_gui_bg.wasm` under `gzip -9` to `4.53 MB` (`4,751,779` bytes vs. the `4,194,304` byte limit), driven primarily by `1.41 MB` raw (`772 KB` `gzip -9`) of embedded `epaint_default_fonts` TrueType tables (`NotoEmoji-Regular.ttf`, `Ubuntu-Light.ttf`, `emoji-icon-font.ttf`, and `Hack-Regular.ttf`) containing thousands of unreferenced glyphs, TrueType bytecode hinting programs, and unused OpenType layout tables—while cold-boot service-worker preload invariants forbid adding extra HTTP font requests.
5. **Latent `wasm32` Test & Smoke Runner Regressions Masked by Budget Gate**: Once the WebAssembly size budget passed, `xtask test-wasm` surfaced four downstream issues: `egui_plot/src/export_modal.rs` used `egui`'s default `SliderClamping::Always` on the `5..=60` `gif_frames` slider (overwriting programmatic `gif_frames = 4` values on initial modal layout), `crates/00_foundation/verified_engine/src/metrics.rs` ran `std::panic::catch_unwind` over an intentional `panic!()` without `#[cfg(panic = "unwind")]` (trapping `wasm32-unknown-unknown`'s `panic = "abort"` runtime with `unreachable`), `scripts/playwright_smoke.py` still defaulted `--dist` and `--trunk-toml` to pre-migration `math_explorer_gui/` instead of `apps/math_explorer_gui/`, and `scripts/wasm_test_runner.py` used `HTTP/1.0` over raw `socketserver.TCPServer`, causing ephemeral loopback connection resets across sequential multi-crate runs.

## Decision

1. **Typed Table & Primitive Export Adapters**: `math_explorer_gui::framework::export_tables` introduces `ExportCell` and `ExportTable` (with deterministic stride capping at `65,536` rows and CWE-1236 CSV/JSON escaping), wired across 3 `dataset_only()` calculators, 8 2D raster simulations, and 6 `ExportPrimitive` visual simulations.
2. **Core Dependency Cleanup**: Remove the unused `rand` dependency from `crates/01_core/oxidize_core/Cargo.toml` (and `crates/04_bindings/markdown_tests/Cargo.toml`) and import `RngCore` from `oxidize_core::rng` in `crates/01_core/oxidize_core/README.md`.
3. **Zero-Copy 8-Wide Plateau Bounds Check**: Refactor `egui_plot/src/poi/plateau.rs` to precompute IEEE-754 finite/sign `(x_min, x_max)` bounds per plateau candidate and match 8-element slice windows directly in place without intermediate chunk copies or closures.
4. **Deterministic Build-Time WASM TrueType Compaction**: Disable `default_fonts` on `eframe` for `wasm32` production builds (preserving `default_fonts` on native desktop builds and `wasm32` `dev-dependencies`) and generate compacted TrueType subsets in `apps/math_explorer_gui/build_stage.rs` into `$OUT_DIR/wasm_fonts/`. Unreferenced glyph outlines are zeroed in `glyf`/`loca` (retaining identical glyph IDs across `cmap`, `hmtx`, and `kern` plus transitive composite glyph components), simple-glyph bytecode instructions and unused hinting/layout tables (`GPOS`, `GSUB`, `hdmx`, `VDMX`, `fpgm`, `prep`, `cvt `, `gasp`, `TTFA`, `DSIG`, `LTSH`) are stripped, `post` is compacted to v3.0, and `MathExplorerApp::new` installs the compacted fonts before Frame 1.
5. **WASM Modal Clamping, Unwind Target Guards, & Browser Harness Fixes**: Set `.clamping(egui::SliderClamping::Edits)` on the `gif_frames` slider in `egui_plot/src/export_modal.rs` (and enable `egui/default_fonts` in `egui_plot` `[dev-dependencies]`), guard `test_run_verified_panic_unwind_preserves_atomic_count` in `crates/00_foundation/verified_engine/src/metrics.rs` with `#[cfg(panic = "unwind")]`, update `scripts/playwright_smoke.py` and `apps/xtask/src/gates.rs` to resolve `apps/math_explorer_gui/Trunk.toml`, and upgrade `scripts/wasm_test_runner.py` to `http.server.ThreadingHTTPServer` with `HTTP/1.1` persistent connections.
6. **Least-Privilege & Deterministic GitHub Actions Hardening**: Narrow root `permissions` in `.github/workflows/ci.yml` from `read-all` to `contents: read`, pin `cargo-binstall` (`1.17.9`) and `cargo-machete` (`0.9.1`) through `./.github/actions/ci-tool-cache`, support `cargo-*` subcommand `--version` verification, and bind `${{ matrix.feature }}` and `${{ matrix.target }}` via `env:` rather than interpolating directly in `run:`.

## Consequences

- **Positive**: `math_explorer_gui_bg.wasm` drops well below the `4 MB` (`4,194,304` byte) ceiling under both `brotli -9` and `gzip -9` while preserving cold-boot zero-extra-request preload parity and full typography across ASCII, Greek, mathematical operators, UI icons, and workspace emojis.
- **Positive**: All CI jobs (`pre-flight`, `build-and-test` across Linux/Windows/macOS/WASM, `feature-matrix`, and `package`) execute deterministically with pinned binary caches and least-privilege `GITHUB_TOKEN` scopes.
- **Trade-off**: Introducing new non-ASCII symbols or emojis outside the scanned workspace/UI codepoint set requires rebuilding `math_explorer_gui` on `wasm32` so `build_stage.rs` includes their glyphs in `$OUT_DIR/wasm_fonts/`.
