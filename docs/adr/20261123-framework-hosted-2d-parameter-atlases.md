# ADR 20261123: Framework-Hosted 2D Parameter Atlases and Zero-Allocation Analytical/Surrogate Cartographers

Date: 2026-11-23

## Status
Accepted (extends [ADR 0012](0012-background-simulation-worker-offload.md), [ADR 0022](0022-unify-preset-state-serialization.md), [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md), [ADR 0035](0035-progressive-parameter-atlas-controller.md), and [ADR 20261123](20261123-fft-lenia-engine-and-gray-scott-kinetics.md))

## Context
Although [ADR 0035](0035-progressive-parameter-atlas-controller.md) introduced `ParameterAtlasController` and `AtlasRunner` for progressive (`8x -> 4x -> 2x -> 1x`) background regime rasterization, adopting 2D parameter-space maps across standalone `InteractiveTool` implementations encountered four structural bottlenecks:
1. **Strict `#[serde(deny_unknown_fields)]` & `URL_JSON_BOUNDS` Budgets**: Tools such as `LeniaTool`, `ParrondoParadoxTool`, `PharmacokineticsTool`, `TurbulenceTool`, and `CapacityFadeTool` enforce `#[serde(deny_unknown_fields)]` state schemas and `< 4 KiB` shareable URL state budgets ([ADR 0022](0022-unify-preset-state-serialization.md)). Embedding bespoke `ParameterAtlasController` UI and persistence fields into every tool created redundant boilerplate and risked breaking historical preset links.
2. **Missing `TheoryDescribable::theory_parameters()` Propagation**: `LeniaTheory`, Gray-Scott `MorphogenesisTheory`, `ParrondoParadoxTool`, `LbmUnified`, `PharmacokineticsTool`, `TurbulenceTool`, and `CapacityFadeTool` either omitted `theory_parameters()` or exposed only a single kinetics mode, preventing `AtlasAxisSpec::from_theory` from deriving canonical axis intervals.
3. **Zero-Allocation Multi-Mode & Surrogate Evaluation**:
   - Switching `MorphogenesisTool` to `MorphogenesisKineticsMode::GrayScott` left its atlas bound to Schnakenberg `(a, b)` axes, overwrote `mode` to `Schnakenberg` on teleport, and left washed-out $v \approx 0$ grids trapped in the trivial $(1, 0)$ fixed point when entering spot-splitting (`Mitosis`/`Coral`) niches.
   - `LeniaTool` lacked a fast zero-allocation niche evaluator to distinguish viable soliton islands from vacuum extinction or blowup without running full 2D FFT steps per pixel, and extinct grids (`total_mass <= 1e-4`) remained empty when sliders or teleports re-entered viable $(R, \mu, \sigma)$ islands.
   - `ParrondoParadoxTool` rendered a static `(p_A, \epsilon)` phase wedge (`&self`) without click/keyboard teleportation, while `solve_parrondo_ratchet` allocated `Vec` buffers per solve.

## Decision
1. **Framework-Hosted `FrameworkAtlasHost` & `InteractiveTool` Hooks**:
   - Extend `InteractiveTool` in [`math_explorer_gui/src/framework/mod.rs`](../../math_explorer_gui/src/framework/mod.rs) with default-no-op hooks (`atlas_axis_pairs`, `active_atlas_coords`, `atlas_context_signature`, `build_atlas_cartographer`, and `apply_atlas_teleport`) and host a lazy `FrameworkAtlasHost` inside `SimulationFramework` ([`math_explorer_gui/src/framework/atlas_host.rs`](../../math_explorer_gui/src/framework/atlas_host.rs)).
   - Tools declaring non-empty `atlas_axis_pairs` automatically gain a top-bar `"🗺 2D Atlas"` toggle and resizable bottom progressive regime explorer without adding fields to `#[serde(deny_unknown_fields)]` serialized states.
   - Add `ParameterAtlasController::replace_axis_pair_options` in [`math_explorer_gui/src/async_sim/atlas/controller.rs`](../../math_explorer_gui/src/async_sim/atlas/controller.rs) so multi-kinetics tools seamlessly swap axis pairs at runtime.
2. **Finite `theory_parameters()` Propagation & Zero-Allocation Cartographers**:
   - Propagate finite `ParameterConstraint` maps across `LeniaTheory`, mode-aware `MorphogenesisTheory` (`Schnakenberg` and `GrayScott`), `ParrondoParadoxTool`, `LbmUnified` (adding configurable `inlet_velocity` defaulting to `0.10`), `PharmacokineticsTool`, `TurbulenceTool`, and `CapacityFadeTool`.
   - **`GrayScottCartographer`** ([`math_explorer_gui/src/tabs/morphogenesis/gray_scott_atlas.rs`](../../math_explorer_gui/src/tabs/morphogenesis/gray_scott_atlas.rs)): Classifies `SaddleNodeWashout` ($f + k > \sqrt{f}/2$), `BistableHomogeneous`, `HopfWave`, `TuringMitosis`, and 2D 5-point `EulerCflUnstable` across `("f", "k")`, `("f", "dt")`, and `("d_u", "d_v")`, overlays the Pearson fold curve $4(f + k)^2 = f$, preserves active kinetics mode on teleport, and auto-reseeds catalyst patches when washed-out $v$ fields enter viable pattern regimes.
   - **`LeniaCartographer`** ([`math_explorer_gui/src/tabs/morphogenesis/lenia/atlas.rs`](../../math_explorer_gui/src/tabs/morphogenesis/lenia/atlas.rs)): Evaluates a stack-only 32-ring radial convolution surrogate (`[[f64; 32]; 32]`) over `("mu", "sigma")` and `("mu", "radius")`, overlays the vacuum stability line $G(0, \mu, \sigma) = 0$, and calls `reseed_current_genome()` when an extinct grid enters a viable soliton niche.
   - **9-State Stack Parrondo Solver & Interactive Phase Wedge** ([`math_explorer_gui/src/tabs/financial_math/parrondo/wedge_interaction.rs`](../../math_explorer_gui/src/tabs/financial_math/parrondo/wedge_interaction.rs)): Implements `solve_parrondo_ratchet_stack` using fixed `[[f64; 9]; 9]` transition matrices and partial-pivoting Gaussian elimination on `[[f64; 10]; 9]` matching `solve_parrondo_ratchet` to `< 1e-12` with zero heap allocations, powers `ParrondoCartographer`, and upgrades `render_phase_wedge_card` (`&mut self`) with live Kelly/drift hover previews and click + keyboard (`Arrow` + `Enter`/`Space`) teleportation.
   - **Domain Cartographers & Challenge Lock Safety**: Add zero-allocation `LbmCartographer` (`("viscosity", "inlet_velocity")`), closed-form steady-state Bateman `PharmacokineticsCartographer` (`("dose_mg", "interval_hours")`, `("ka", "ke")`), `TurbulenceCartographer`, and `CapacityFadeCartographer`, while guarding inverse-challenge locked parameters during atlas teleports.

## Consequences
- **Positive**: Standalone and unified tools gain non-blocking 2D regime exploration, analytical bifurcation overlays, WCAG 2.2 AA `HighContrast` (`>= 3.0:1` on `#000000`) palettes, and click/keyboard teleportation with `0` heap allocations inside `VerifiedEngine::run_verified` and zero URL state bloat.
- **Neutral**: Tools that do not opt into framework-hosted atlases leave `atlas_axis_pairs()` at `&[]` and incur zero UI or memory overhead.
