# ADR 0044: Checked Companion APIs, Typed Domain Errors, and Human-Readable Diagnostics

## Status
Accepted (extends [ADR 0027](0027-enforce-workspace-clippy-lints.md), [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md), and [ADR 0042](0042-hierarchical-umbrella-errors-and-diagnostic-bus-helpers.md))

## Context
[`math_explorer`](../../math_explorer/src/lib.rs) exposes a unified scientific computing SDK across `math_commons`, `pure_math`, and six `domain_*` crates. Four error-handling inconsistencies undermined downstream programmatic error recovery, NASA Power of 10 zero-allocation guarantees, and diagnostic readability:
1. **Missing `ClimateError` and Untyped String `Result` Signatures**: [`crates/domain_climate`](../../crates/domain_climate/src/lib.rs) lacked a crate-level `error` module (`Cera::new*` returned `Result<Self, String>`), and `17` public domain functions across `domain_ai`, `domain_applied`, `domain_climate`, `domain_epidemiology`, `domain_physics`, and `oxidize_core`, plus `27` bounded primitive constructors and operators in [`crates/math_commons/src/primitives.rs`](../../crates/math_commons/src/primitives.rs), returned `Result<_, String>` or `Result<_, &'static str>`. Allocating `format!(...)` strings on hot bounds failures also violated the post-initialization zero-allocation rule enforced by `VerifiedEngine`.
2. **Opaque Unit Errors (`Result<_, ()>`)**: [`Integer::{parse, from_str_radix, pow_mod, invert}`](../../crates/pure_math/src/math_types.rs) and [`egui_plot/src/latex.rs`](../../egui_plot/src/latex.rs) suppressed `#[allow(clippy::result_unit_err)]` and discarded radix, literal, zero-modulus, and non-invertible failure causes.
3. **Panicking Public Entrypoints Without Fallible Companions**: Public constructors and algebra/tensor entrypoints (`QSeries` division, `Fp` inversion, `CyclicElement`, `Zn`, `Permutation`, `NthRootSurface`, `SchwarzChristoffel`, `StencilOperators`, `FusedStencilStepper`, `MultiHeadAttention`, `BoxSet`, `LatticeState`, `TrackingFilter`, and `domain_climate` losses/convolutions) asserted or divided directly without `try_*` or `checked_*` counterparts for untrusted caller inputs.
4. **Raw `{:?}` Debug Formatting in `Display`**: `13` public error enums across [`crates/pure_math/src/error.rs`](../../crates/pure_math/src/error.rs), [`crates/domain_applied/src/error.rs`](../../crates/domain_applied/src/error.rs), [`crates/domain_epidemiology/src/error.rs`](../../crates/domain_epidemiology/src/error.rs), and [`crates/domain_physics/src/error.rs`](../../crates/domain_physics/src/error.rs) implemented `Display` via `write!(f, "{:?}", self)`, leaking Rust struct syntax into UI banners and `Diagnostic::metadata` descriptions (alongside `Dimension(n)` in `MathError::DimensionMismatch`).

## Decision
1. **Introduce `ClimateError` and Complete Typed Domain Error Coverage**:
   - Add [`crates/domain_climate/src/error.rs`](../../crates/domain_climate/src/error.rs) defining `ClimateError` with `thiserror::Error`, `diagnostics::Diagnostic`, and `#[from] MathError`, re-export it from [`crates/domain_climate/src/climate/mod.rs`](../../crates/domain_climate/src/climate/mod.rs), [`math_explorer/src/error.rs`](../../math_explorer/src/error.rs), and [`math_explorer/src/prelude.rs`](../../math_explorer/src/prelude.rs), and wire `Error::Climate(ClimateError)` into [`math_explorer::error::Error`](../../math_explorer/src/error.rs) (`50` leaf errors + `6` crate umbrellas).
   - Add stack-allocated `OutOfBounds`, `StrictlyOutOfBounds`, and `InvalidPermutation` variants to [`MathError`](../../crates/math_commons/src/error.rs) and migrate all `27` `UnitInterval`, `PositiveFloat`, and `NonNegativeFloat` `Result` signatures in [`crates/math_commons/src/primitives.rs`](../../crates/math_commons/src/primitives.rs) off `String`.
   - Migrate all remaining untyped `String`, `&'static str`, and `()` `Result` signatures across `pure_math`, `domain_ai`, `domain_applied`, `domain_climate`, `domain_epidemiology`, `domain_physics`, `oxidize_core`, and `egui_plot` to stack-allocated typed enum variants (`NumberTheoryError`, `AIError`, `EngineeringError`, `GameTheoryError`, `ClimateError`, `EpidemiologyError`, `DoseFluenceError`, `FluidError`, `RadarError`, `SolidStateError`, `StandardModelError`, `StatMechError`, `WorkspaceError`, and `LatexParseError`), eliminating every `#[allow(clippy::result_unit_err)]` suppression in the repository.
2. **Provide `checked_*` and `try_*` Companion Entrypoints**:
   - Add [`QSeries::checked_div`](../../crates/pure_math/src/pure_math/number_theory/q_series.rs) and [`Fp::checked_inverse`](../../crates/pure_math/src/pure_math/algebra/fields.rs) while preserving `std::ops::Div` and `Field::multiplicative_inverse` trait contracts.
   - Add `try_new` / `try_*` companions for [`CyclicElement`](../../crates/pure_math/src/pure_math/algebra/group.rs), [`Zn`](../../crates/pure_math/src/pure_math/algebra/group.rs), [`Permutation`](../../crates/pure_math/src/pure_math/algebra/group.rs), [`NthRootSurface`](../../crates/pure_math/src/pure_math/analysis/complex/surfaces.rs), [`SchwarzChristoffel`](../../crates/pure_math/src/pure_math/analysis/complex/mapping.rs), [`StencilOperators`](../../crates/pure_math/src/pure_math/analysis/pde/fused_stepper.rs), [`FusedStencilStepper`](../../crates/pure_math/src/pure_math/analysis/pde/fused_stepper.rs), [`MultiHeadAttention`](../../crates/domain_ai/src/ai/transformer/attention.rs), [`BoxSet`](../../crates/domain_applied/src/applied/game_theory/equilibrium.rs), [`LatticeState`](../../crates/domain_physics/src/physics/fluid_dynamics/lattice_boltzmann/state.rs), [`TrackingFilter`](../../crates/domain_physics/src/physics/medical/radar_gating/tracking.rs), [`try_mse_loss`](../../crates/domain_climate/src/climate/loss.rs), [`try_earth_movers_distance`](../../crates/domain_climate/src/climate/loss.rs), [`try_conv1d`](../../crates/domain_climate/src/climate/tensor_ops.rs), and [`try_conv_transpose1d`](../../crates/domain_climate/src/climate/tensor_ops.rs), delegating existing `new` / operator wrappers to them.
3. **Standardize `thiserror::Error` Human-Readable `Display` Messages**:
   - Replace all `write!(f, "{:?}", self)` `Display` implementations and `MathError::DimensionMismatch`'s `{:?}` field formatting with explicit `#[error("...")]` sentences, verified across all `28` facade error enums in [`math_explorer/tests/error_formatting.rs`](../../math_explorer/tests/error_formatting.rs).

## Consequences
- **Positive**: Zero public library signatures in [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json) or [`crates/math_commons/src/primitives.rs`](../../crates/math_commons/src/primitives.rs) return `Result` with `String`, `&'static str`, or `()`, and zero `#[allow(clippy::result_unit_err)]` suppressions remain.
- **Positive**: Hot-path bounds, integer, and solver failures construct stack-only `Copy` / scalar payloads with zero heap allocations inside `VerifiedEngine::run_verified`, while `Display` and `Diagnostic::metadata` emit clean sentences when surfaced to UI consumers.
- **Neutral**: Existing panicking `new` constructors, operator traits (`Div`), algebraic traits (`Monoid`, `Field`), and inner `domain_climate` layer kernels remain intact for ergonomic trusted-input call sites, with `api_baseline.json` updated to record the expanded checked API surface.
