# ADR 0047: Unified Graph Topology Exchange, Parameterized Complexity Overlays, and Empirical Network Imports

## Status
Accepted (extends [ADR 0009](0009-reusable-graph-layout-algorithms.md), [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), [ADR 0038](0038-prime-exponent-fractran-vm-and-minsky-gui.md), and [ADR 0039](0039-network-epidemic-containment-primitives.md))

## Context
Seven interactive graph, network, and state-machine tools in `math_explorer_gui` (`GraphEditorTool`, `AlgorithmVisualizerTool`, `NetworkMetricsTool`, `NetworkPropagationTool`, `NeuralNetworkVizTool`, `FractranMachineTool`, and `BraessNetworkParadoxTool`) previously maintained isolated vertex and edge representations without any standard topology import or export format. Five of those tools returned `ExportCapabilities::none()`, leaving users unable to export edited graphs, shortest-path trees, centrality and parameterized complexity annotations, epidemic containment networks, Hodgkin-Huxley synaptic circuits, Minsky counter-machine transition diagrams, or Wheatstone Wardrop flows to Graphviz (`.dot`), Gephi/Cytoscape (`.graphml`), standalone LaTeX `TikZ` (`.tex`), vector `.svg`, or `.csv` tables. Furthermore, [`crates/pure_math/src/pure_math/graph_theory/parameters/degree.rs`](../../crates/pure_math/src/pure_math/graph_theory/parameters/degree.rs) (`degeneracy`) and [`crates/pure_math/src/pure_math/graph_theory/parameters/modulator.rs`](../../crates/pure_math/src/pure_math/graph_theory/parameters/modulator.rs) (`vertex_cover`) were not surfaced in `NetworkMetricsTool`, and `GraphTheoryTab` tools could not share a live edited or imported graph.

## Decision
1. **Pure-Rust Bounded `graph_io` Codec (`pure_math`)**:
   - Add [`crates/pure_math/src/pure_math/graph_theory/graph_io/mod.rs`](../../crates/pure_math/src/pure_math/graph_theory/graph_io/mod.rs) defining `GraphTopologyDocument`, `TopologyNode`, `TopologyEdge`, `TopologyFormat`, and `TopologyCodecError` with zero external XML or parser-generator dependencies to preserve the `< 3 MiB` compressed WASM budget.
   - Provide deterministic serializers for Graphviz `.dot`, Gephi/Cytoscape `.graphml`, standalone compilable LaTeX `TikZ` (`.tex`), vector `.svg`, and canonical `.csv` node/edge tables, alongside strictly iterative bounded parsers for `.dot` (`MAX_DOT_BRACE_DEPTH = 32`), `.graphml` (explicitly rejecting `<!DOCTYPE` and `<!ENTITY` declarations), and `.csv`/`.tsv` enforcing `<= 2 MiB`, `<= 500` nodes, `<= 5,000` edges, UTF-8 BOM stripping, and automatic circular layout fallback.
2. **Deferred `SimulationFramework` Topology File & Clipboard Dispatch (`egui_plot` & `math_explorer_gui`)**:
   - Extend [`egui_plot/src/file_io.rs`](../../egui_plot/src/file_io.rs) `infer_mime_type` with `.dot`/`.gv` (`text/vnd.graphviz`), `.graphml` (`application/graphml+xml`), and `.tex` (`application/x-tex`).
   - Extend [`math_explorer_gui/src/framework/export_types.rs`](../../math_explorer_gui/src/framework/export_types.rs), [`math_explorer_gui/src/framework/export_queue.rs`](../../math_explorer_gui/src/framework/export_queue.rs), and [`math_explorer_gui/src/framework/export_topology.rs`](../../math_explorer_gui/src/framework/export_topology.rs) with `ExportCapabilities::topology`, `TopologyDot`, `TopologyGraphMl`, `TopologyTikz`, `TopologySvg`, and `TopologyCsv` file and clipboard targets so hybrid tools (`FractranMachineTool`, `BraessNetworkParadoxTool`, and Braess-enabled `GraphEditorTool`) retain 1D `egui_plot` `Csv`/`Png`/`Svg` exports without format collisions.
3. **Cross-Tool `GraphTheoryTab` Sync, `degeneracy`/`vertex_cover` Overlays, and Empirical Contact Imports**:
   - Add [`math_explorer_gui/src/tabs/graph_theory/topology_sync.rs`](../../math_explorer_gui/src/tabs/graph_theory/topology_sync.rs) to import `.dot`, `.graphml`, and `.csv`/`.tsv` files via `spawn_open_file_dialog` and synchronize topologies live across `GraphEditorTool`, `AlgorithmVisualizerTool`, and `NetworkMetricsTool` with `TwinSlotLiveRegion` screen-reader announcements.
   - Expose `degeneracy` and 2-approximate `vertex_cover` in [`math_explorer_gui/src/tabs/graph_theory/network_metrics.rs`](../../math_explorer_gui/src/tabs/graph_theory/network_metrics.rs) (sidebar summary, double-ring canvas highlight, and exported node/graph attributes).
   - Add [`math_explorer_gui/src/tabs/epidemiology/network_propagation/topology_io.rs`](../../math_explorer_gui/src/tabs/epidemiology/network_propagation/topology_io.rs) enabling empirical contact network imports for budgeted vaccinations and symmetric edge quarantines while keeping URL state compact within `URL_JSON_BOUNDS` and simulation stepping zero-allocation under `VerifiedAllocator`.

## Consequences
- **Positive**: All seven graph and automata tools export publication-ready `.dot`, `.graphml`, LaTeX `TikZ`, `.svg`, and `.csv` topologies (via file download and clipboard copy on both desktop and `wasm32-unknown-unknown`), reducing `unsupported_tool_count` in [`math_explorer_gui/src/framework/deferred_export_audit_tests.rs`](../../math_explorer_gui/src/framework/deferred_export_audit_tests.rs) from `16` to `11`.
- **Positive**: `GraphTheoryTab` workflows now form a continuous import/edit/traverse/analyze pipeline with `degeneracy` and `vertex_cover` parameterized complexity inspection, and `NetworkPropagationTool` evaluates containment budgets on arbitrary imported contact graphs up to `500` vertices.
- **Neutral**: Full TikZ macro parsing and arbitrary Graphviz layout attributes remain out of scope; `.tex` and `.svg` serve as deterministic export targets while `.dot`, `.graphml`, and `.csv`/`.tsv` provide bounded roundtrip interchange.
