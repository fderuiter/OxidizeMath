# ADR 0034: Harden Verification Macros with Spanned Diagnostics, `allow_recursion`, Dynamic Workspace Paths, and Facade Re-Exports

## Status
Accepted (extends [ADR 0006](0006-decouple-math-metadata.md), [ADR 0022](0022-cleanup-verification-macros-dead-code.md), and [ADR 0027](0027-remove-unread-verification-macro-accumulators.md))

## Context
Four soundness, diagnostic, and dependency-hygiene defects existed across [`crates/verified_engine_macros`](../../crates/verified_engine_macros/src/lib.rs) and its public facades:
1. **Silent Pass-Throughs, Substring Bypass, and Unspanned JSON Errors in `#[verified]`**: `#[verified]` silently passed unsupported items (`struct`, `enum`, `mod`, `impl`) through unchanged, matched `opt_out` via raw `attr.to_string().contains("opt_out")`, emitted unspanned JSON strings inside `compile_error!` for recursion and statement-limit violations, injected non-`const` metric calls into `const fn` items (`E0015`), and forced delegating trait methods (`self.step()` / `self.copy_from()`) to use `opt_out`—disabling statement-limit enforcement, runtime `ComplexityMetrics` instrumentation, and AST verification counts in [`crates/oxidize_core/src/ast_visitor.rs`](../../crates/oxidize_core/src/ast_visitor.rs).
2. **Swallowed Parse Errors, Float Panics, and Unspanned Casts in `#[derive(Theory)]`**: `#[derive(Theory)]` discarded malformed `#[theory(...)]` metadata via `let _ = attr.parse_nested_meta(...)`, accepted only `Lit::Float` bounds (panicking on overflowing literals like `1e999` or invalid `min > max` / `step <= 0.0` ranges downstream), failed silently on `enum` / `union` / tuple `struct` inputs, and emitted unspanned `as f64` / `as #field_ty` casts that pointed errors at the derive attribute rather than the offending field type.
3. **Hardcoded `../../` Paths and Named Tracker Constants in `#[embed_theory]`**: [`crates/verified_engine_macros/src/embed_theory.rs`](../../crates/verified_engine_macros/src/embed_theory.rs) hardcoded `../../` relative to `CARGO_MANIFEST_DIR` (breaking top-level crates like [`math_explorer`](../../math_explorer/Cargo.toml)), discarded `LitStr` spans on file/label errors, and emitted named `const _EMBEDDED_THEORY_TRACKER_*: &str` items with `#[allow(dead_code)]` that collided on shared labels (`E0428`) and failed inside `impl Trait for Type` blocks (`E0438`).
4. **Leaked Internal Crate Paths and `cargo-machete` Suppressors**: Macro expansions referenced bare `verified_engine::...` and `scientific_metadata::...` paths, forcing six domain `Cargo.toml` manifests (`domain_ai`, `domain_applied`, `domain_biology`, `domain_climate`, `domain_epidemiology`, and `pure_math`) to carry unused `scientific_metadata` dependencies and `[package.metadata.cargo-machete]` ignores while leaving [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs) without re-exports for `verified_engine` and `scientific_metadata`.

## Decision
1. **Harden `#[verified]` Parsing, Diagnostics, `const fn`, and `allow_recursion`**:
   - Modularize `#[verified]` in [`crates/verified_engine_macros/src/verified.rs`](../../crates/verified_engine_macros/src/verified.rs) to accept `ItemFn`, `ImplItemFn`, and `TraitItemFn` (including bodyless trait signatures) while rejecting unsupported items with plain-text `syn::Error` diagnostics spanned to the item keyword.
   - Parse `#[verified(...)]` strictly with `syn::meta::parser`, accepting only `opt_out = "reason"` and `allow_recursion = "reason"` with non-empty string literals.
   - Keep the 60-statement limit, runtime `ComplexityMetrics` instrumentation, and [`crates/oxidize_core/src/ast_visitor.rs`](../../crates/oxidize_core/src/ast_visitor.rs) verification counts active under `allow_recursion`, skipping only the direct-recursion check. On `const fn` items, enforce all static AST checks while omitting runtime metric calls.
   - Emit plain-text spanned `syn::Error` diagnostics for compile-time violations while preserving `runtime_violation!` JSON payloads strictly for runtime allocator aborts in [`crates/verified_engine/src/allocator.rs`](../../crates/verified_engine/src/allocator.rs).
2. **Accumulate `#[derive(Theory)]` Errors, Validate Finite Numeric Bounds, and Span Casts**:
   - Implement `#[derive(Theory)]` in [`crates/verified_engine_macros/src/theory.rs`](../../crates/verified_engine_macros/src/theory.rs) with `syn::Error::combine` accumulation across struct-level (`description`, `phonetic`, `citation`) and field-level (`min`, `max`, `step`) attributes, rejecting enums, unions, and tuple structs explicitly.
   - Accept signed integer and floating-point bound literals, reject non-finite/overflowing values (`!val.is_finite()`), `min > max`, and `step <= 0.0` before code generation with zero panics, and span field casts to `field.ty.span()`.
3. **Dynamic Workspace Discovery and Unnamed `const _` Trackers in `#[embed_theory]`**:
   - Walk ancestors of `CARGO_MANIFEST_DIR` in [`crates/verified_engine_macros/src/embed_theory.rs`](../../crates/verified_engine_macros/src/embed_theory.rs) to locate the `[workspace]` root dynamically and compute exact relative `include_str!` paths for crates at any directory depth.
   - Preserve `LitStr` and attribute spans on file, label, shadow-mirroring, and semantic-integrity errors, and emit unnamed `const _: &str = include_str!(...);` trackers without `#[allow(dead_code)]`.
4. **Hygienic Facade Re-Exports and Domain Manifest Cleanup**:
   - Re-export `#[doc(hidden)] pub use scientific_metadata;` from [`crates/verified_engine/src/lib.rs`](../../crates/verified_engine/src/lib.rs) and `pub use {scientific_metadata, verified_engine};` from [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs), resolving target crate paths via [`crates/verified_engine_macros/src/crate_paths.rs`](../../crates/verified_engine_macros/src/crate_paths.rs) with zero new external dependencies.
   - Remove the unnecessary `opt_out` on `LorenzSystem::step` in [`crates/domain_physics/src/physics/chaos/lorenz.rs`](../../crates/domain_physics/src/physics/chaos/lorenz.rs), migrate delegating trait methods in [`crates/domain_physics/src/physics/fluid_dynamics/lattice_boltzmann/algorithms.rs`](../../crates/domain_physics/src/physics/fluid_dynamics/lattice_boltzmann/algorithms.rs), [`crates/domain_biology/src/biology/morphogenesis/mod.rs`](../../crates/domain_biology/src/biology/morphogenesis/mod.rs), and [`crates/pure_math/src/pure_math/analysis/ode/state.rs`](../../crates/pure_math/src/pure_math/analysis/ode/state.rs) to `allow_recursion`, and delete unused `scientific_metadata` dependencies and `cargo-machete` ignores from six domain manifests.

## Consequences
- **Positive**: All 13 compile-time failure modes across `#[verified]`, `#[derive(Theory)]`, and `#[embed_theory]` produce deterministic, plain-text `rustc` errors underlined at the exact offending AST token with zero proc-macro panics.
- **Positive**: Delegating trait implementations remain covered by the 60-statement limit, runtime `ComplexityMetrics` tracking, and `AstVisitor` verification metrics, and downstream callers can use all verification macros exclusively through `math_explorer` or `verified_engine`.
- **Neutral**: Regenerated [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json) to record the intentional public facade re-exports in `verified_engine` and `math_explorer`.
