# ADR 20261123: In-Place Acoustic Luthiery Sonification, RLE Soundboard Sculpting, and Phononic Metamaterial Refraction

## Status
Accepted (extends [ADR 0040](0040-dual-backend-web-audio-sonification.md), [ADR 0042](0042-2d-chladni-plate-and-wave-tank-solver.md), and [ADR 0045](0045-spatial-brush-kit-and-field-sculpting.md))

## Context
[`ChladniWaveTankTool`](../../apps/math_explorer_gui/src/tabs/analysis/chladni_wave_tank.rs) and [`Wave2DSolver`](../../crates/03_domains/pure_math/src/pure_math/analysis/pde/wave_2d.rs) (introduced in [ADR 0042](0042-2d-chladni-plate-and-wave-tank-solver.md)) previously lacked continuous signed pickup velocity probes, flexural stiffness rib modulation, and multi-role medium sculpting: `rebuild_masks` overwrote `wave_speed_mask` with rigid preset geometry without RLE soundboard persistence, and condensed-matter phonon dispersion and Bravais lattice primitives in [`crates/domain_physics/src/physics/solid_state/phonons.rs`](../../crates/03_domains/domain_physics/src/physics/solid_state/phonons.rs) and [`lattice.rs`](../../crates/03_domains/domain_physics/src/physics/solid_state/lattice.rs) had zero interactive 2D wave callers.

## Decision
1. **Zero-Allocation Signed Point-Probe Readers, Multi-Mode 2D FFT Extraction, and Flexural Rib Scaling (`pure_math`)**:
   - Add [`crates/pure_math/src/pure_math/analysis/pde/wave_2d/probes.rs`](../../crates/03_domains/pure_math/src/pure_math/analysis/pde/wave_2d/probes.rs) providing `#[verified_engine::verified]` `WaveProbeSample` and bilinear signed displacement and velocity readers (`sample_displacement_bilinear`, `sample_velocity_bilinear`, `sample_probe`) without heap allocation.
   - Extend [`SpectralAnalyzer2D`](../../crates/03_domains/pure_math/src/pure_math/analysis/pde/wave_2d/spectral.rs) with `top_peaks(&self, out: &mut [SpectralPeak2D]) -> usize` using 3x3 non-DC local-maximum suppression over the upper half-plane spectrum to extract up to 8 modal overtones in place.
   - Modulate Kirchhoff-Love biharmonic flexural stiffness by `wave_speed_mask[idx]^2` in `advance_single_cell` and `safe_substep_plan` so sculpted soundboard ribs and slow lenses shift plate eigenfrequencies while preserving bit-exact baseline behavior when `wave_speed_mask == 1.0`.
2. **Modal & Phase-Velocity Web Audio Sonification (`math_explorer_gui::audio`)**:
   - Add `#[cfg(feature = "pure_math")]` [`chladni_plate_frame`](../../apps/math_explorer_gui/src/audio/mappings/acoustics.rs) mapping top-8 `SpectralPeak2D` wavenumber ratios, `analytic_clamped_square_omega` flexural dispersion, and signed pickup phase velocity into an 8-voice `SonificationFrame` with custom `HarmonicWeights` and stereo pickup panning.
   - Embed [`render_sonification_panel`](../../apps/math_explorer_gui/src/audio/ui.rs) inside [`chladni_wave_tank/ui.rs`](../../apps/math_explorer_gui/src/tabs/analysis/chladni_wave_tank/ui.rs) with user-gesture mute unlock, master volume, Fourier timbre override, deterministic 16-bit `.wav` export, and WCAG 2.2 AA `Role::Meter` telemetry.
3. **Bounded `< 4 KiB` RLE Soundboard & Refractive Sculpting (`SpatialBrushKit`)**:
   - Add [`sculpt.rs`](../../apps/math_explorer_gui/src/tabs/analysis/chladni_wave_tank/sculpt.rs) and [`sculpt_codec.rs`](../../apps/math_explorer_gui/src/tabs/analysis/chladni_wave_tank/sculpt_codec.rs) implementing `InteractiveTool::on_brush` via `SpatialBrushKit`, `rasterize_disk_stroke`, and `encode_rle_mask` / `decode_rle_mask` across quantized `u8` acoustic roles (`0` baseline, `1` rigid clamp, `2..=7` spruce/carbon ribs, graded-index lenses, and phononic scatterers).
   - Persist `#[serde(default, skip_serializing_if = "Vec::is_empty")] sculpt_rle: Vec<[u32; 2]>` and `(pickup_x, pickup_y)` on `ChladniWaveTankState` with `max_array_len = 1_024` and automatic block coarsening above `400` runs so sculpted soundboards roundtrip inside `< 4,096` URL JSON bytes (`URL_JSON_BOUNDS`) without clearing user edits.
4. **Feature-Gated Phononic Crystals, AST Refractive Potentials, and Dispersion Overlays (`#[cfg(feature = "physics")]`)**:
   - Add [`metamaterial.rs`](../../apps/math_explorer_gui/src/tabs/analysis/chladni_wave_tank/metamaterial.rs) projecting `solid_state::lattice` Bravais `UnitCell` sites (`SC`, `BCC`, `FCC`) and precompiled 2D [`math_commons::ast::CompiledExpr`](../../crates/02_engines/math_commons/src/ast/compiled.rs) refractive profiles onto `wave_speed_mask` (with zero-allocation `eval_2d` evaluation).
   - Add `SecondaryPlotMode::PhononDispersion` overlaying `solid_state::phonons::{acoustic_dispersion, optical_dispersion}` and `debye_heat_capacity_low_temp` against live radial 2D FFT wavenumbers $|k|$.

## Consequences
- **Positive**: Users can carve violin bracing, Luneburg lenses, and Bravais phononic crystals directly on the 128x128 wave domain, watch `4,000` Chladni sand grains reorganize, hear live modal overtone shifts, export 16-bit `.wav` clips, and share `< 4 KiB` URLs across desktop and `wasm32-unknown-unknown` builds.
- **Positive**: Hot-loop time-stepping, bilinear probe sampling, `top_peaks` extraction, and `chladni_plate_frame` synthesis execute with zero heap allocations under `VerifiedAllocator::lock_allocations()`, while keyboard reticle sculpting and `Role::Meter` preserve non-trapping `Tab` focus traversal.
- **Neutral**: Full 3D finite-element tetrahedral plate meshing and external audio sample uploads remain out of scope so all state buffers remain pre-allocated on the 2D uniform grid.
