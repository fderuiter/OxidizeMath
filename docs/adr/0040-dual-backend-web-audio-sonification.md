# ADR 0040: Dual-Backend Web Audio Sonification, Stack-Allocated `SonificationFrame`, and Accessible Visual Metering

## Status
Accepted (extends [ADR 0008](0008-finite-state-solver-guard.md), [ADR 0012](0012-background-simulation-worker-offload.md), [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md), and [ADR 0033](0033-wasm32-browser-tests-and-playwright-ci-smoke-gate.md))

## Context
Interactive simulations across neuroscience, quantum mechanics, nonlinear chaos, and number theory produce multi-frequency, transient, and polyphonic dynamics—such as Hodgkin–Huxley action potentials, coupled ring-oscillator phase locking, multi-mode Schrödinger beat interference, Lorenz lobe switching, logistic period-doubling cascades, and prime harmonic ratios—that are difficult to perceive through 60 Hz visual plots alone:
1. **Zero-Allocation and Worker-Boundary Constraints**: Background simulation threads and `wasm32` cooperative ticks communicate with the UI exclusively via [`StateSnapshot`](../../math_explorer_gui/src/async_sim/state.rs) while NASA Power of 10 Rule 3 (`VerifiedAllocator`) forbids heap allocations inside inner simulation and synthesis loops.
2. **Strict Browser CSP, Autoplay, and Safety Invariants**: Production deployments enforce `script-src 'self' 'wasm-unsafe-eval'` (precluding blob or external `AudioWorklet` scripts) and browser autoplay policies forbid instantiating or resuming an `AudioContext` prior to an explicit user click or keypress. Unclamped solver states or abrupt parameter jumps also risk ultrasonic/DC output, clipping, or audible clicks.
3. **Deterministic Native Verification and WCAG AA Accessibility**: Browser `AudioContext` nodes cannot run in headless `cargo test` on native hosts, and WCAG 2.2 AA requires deaf and hard-of-hearing parity via high-contrast visual level/frequency readouts alongside polite ARIA announcements on fault or WebGL context recovery without mutating [`accessibility.rs`](../../math_explorer_gui/src/accessibility.rs).

## Decision
1. **Stack-Allocated `SonificationFrame` Across `StateSnapshot`**:
   - Define [`SonificationFrame`](../../math_explorer_gui/src/audio/frame.rs) (`Copy`, 8 polyphonic [`VoiceSpec`](../../math_explorer_gui/src/audio/frame.rs) strips, [`WaveformPreset`](../../math_explorer_gui/src/audio/frame.rs), optional stack [`HarmonicWeights`](../../math_explorer_gui/src/audio/frame.rs), filtered chaotic noise controls, and master gain) and carry `sonification: Option<SonificationFrame>` on [`StateSnapshot`](../../math_explorer_gui/src/async_sim/state.rs).
   - Add [`QuantumState::project_spatial_modes`](../../crates/domain_physics/src/physics/quantum/types.rs) to project complex wavefunctions onto orthonormal spatial Fourier modes on the stack before probability collapse (`norm_sqr()`), preserving complex amplitudes and phase velocities for acoustic synthesis.
2. **Dual-Backend `SonificationBackend` Trait and Fourier `PeriodicWave` Synthesis**:
   - Define [`SonificationBackend`](../../math_explorer_gui/src/audio/backend.rs) with two implementations:
     - [`WebAudioNodeBackend`](../../math_explorer_gui/src/audio/web_audio.rs) (`wasm32-unknown-unknown`): builds native `OscillatorNode`, `PeriodicWave` (populated from `calculate_fourier_coefficients_real` in [`continuous.rs`](../../crates/pure_math/src/pure_math/analysis/transforms/fourier/continuous.rs)), `BiquadFilterNode`, `StereoPannerNode`, `GainNode`, `DynamicsCompressorNode`, and `AnalyserNode` graphs without `AudioWorklet` scripts. Audio defaults to muted (`graph: None`) until an explicit user gesture calls `set_muted_from_user_gesture(false)`, clamps frequencies to `20.0..=8000.0 Hz`, smooths parameters via `AudioParam::set_target_at_time` (`15 ms`), and enforces a `-3.0 dBFS` master ceiling.
     - [`OfflinePcmSynthesizer`](../../math_explorer_gui/src/audio/synth.rs): pre-allocates stereo PCM storage once at construction and synthesizes band-limited polyphonic FM, Fourier harmonics, stereo pan, chaotic noise, and `-3.0 dBFS` soft limiting with zero heap allocations for `rustfft` spectral tests and 16-bit stereo RIFF `.wav` export ([`wav.rs`](../../math_explorer_gui/src/audio/wav.rs) + [`spawn_save_binary_file_dialog`](../../math_explorer_gui/src/web_io.rs)).
3. **Domain Mappings, `<= 30 ms` Fault Recovery, and Accessible Visual Metering**:
   - Map mathematical invariants in [`audio/mappings/`](../../math_explorer_gui/src/audio/mappings/mod.rs) across [`hodgkin_huxley.rs`](../../math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs), [`spike_analysis.rs`](../../math_explorer_gui/src/tabs/neuroscience/spike_analysis.rs), [`neural_network_viz.rs`](../../math_explorer_gui/src/tabs/neuroscience/neural_network_viz.rs), [`wave_sim.rs`](../../math_explorer_gui/src/tabs/quantum/wave_sim.rs), [`attractors/runner.rs`](../../math_explorer_gui/src/tabs/chaos/attractors/runner.rs), [`bifurcation.rs`](../../math_explorer_gui/src/tabs/chaos/bifurcation.rs), and [`factorization.rs`](../../math_explorer_gui/src/tabs/number_theory/factorization.rs).
   - Ramp gain to silence (`3 ms` time constant, reaching `< -80 dBFS` within `<= 30 ms`) and suspend playback on `PlaybackAction::Pause`, numerical solver divergence, [`webgl_recovery::on_context_lost`](../../math_explorer_gui/src/webgl_recovery.rs), tool switches, and window blur, dispatching polite status updates through `crate::accessibility::announce_status`.
   - Persist non-mute [`AcousticSettings`](../../math_explorer_gui/src/audio/settings.rs) (`gain`, `pitch_scale`) across JSON presets and compact `#tab=...&tool=...&state=...` URL hydration alongside spatial sculpt payloads while always booting muted, and wire `ExportFormat::Wav` action-bar dispatch plus [`MriTool`](../../math_explorer_gui/src/tabs/mri/sonification.rs) NMR FID and [`PrimeSpiralWidget`](../../math_explorer_gui/src/tabs/number_theory/prime_spiral/sonification.rs) Ulam prime-gap synthesis.
   - Render [`render_sonification_panel`](../../math_explorer_gui/src/audio/ui.rs) with an `AccessKit` `Role::Meter` readout displaying peak `dBFS`, dominant `Hz`, and `-3.0 dBFS` ceiling markers across `Dark`, `Light`, and `HighContrast` palettes.

## Consequences
- **Positive**: Users can hear spike trains, pentatonic neural synchronization, quantum beat frequencies, chaotic attractors, period-doubling subharmonics, and prime just-intonation chords in the browser under strict `'self'` CSP or export deterministic `.wav` clips offline.
- **Positive**: Every acoustic mapping and DSP path is verified natively via `rustfft` spectral assertions and 1,000-step `VerifiedEngine::run_verified` zero-allocation checks, alongside headless Chrome `#[wasm_bindgen_test]` coverage of `WebAudioNodeBackend`.
- **Neutral**: Adding new sonified tools requires only populating `StateSnapshot::sonification` (for worker tools) or calling `render_sonification_panel` with a pure stack `SonificationFrame` mapping function.
