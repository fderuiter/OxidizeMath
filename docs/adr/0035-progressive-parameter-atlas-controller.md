# ADR 0035: Progressive Asynchronous 2D Parameter Regime Atlas and Washout Auto-Reseeding

## Status
Accepted (extends [ADR 0012](0012-background-simulation-worker-offload.md), [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md), and [ADR 0033](0033-wasm32-browser-tests-and-playwright-ci-smoke-gate.md))

## Context
Interactive scientific tabs exposed scalar 1D sliders (`egui::Slider`) and 1D parameter tornado bars (`SensitivityEngine`) while leaving higher-dimensional dynamical regime geometry opaque:
1. **Blind Parameter Exploration**: In Schnakenberg reaction-diffusion ([`math_explorer_gui/src/tabs/morphogenesis/tool.rs`](../../math_explorer_gui/src/tabs/morphogenesis/tool.rs)), the Turing pattern-formation domain occupies a curved island in $(a, b, D_u, D_v, \Delta t)$ space bounded by washout ($\det(J_{k_*}) \ge 0$), homogeneous Hopf oscillation ($\operatorname{tr}(J_0) > 0$), and explicit Forward Euler CFL blow-up ($|1 + \Delta t \lambda| > 1$). Similarly, the Kermack-McKendrick SIR tab ([`math_explorer_gui/src/tabs/epidemiology/sir.rs`](../../math_explorer_gui/src/tabs/epidemiology/sir.rs)) left `calculate_final_size` in [`crates/domain_epidemiology/src/epidemiology/analytics.rs`](../../crates/domain_epidemiology/src/epidemiology/analytics.rs) unwired to the UI, and Hodgkin-Huxley ([`math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs`](../../math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs)) required blind trial-and-error across $(I_{\text{ext}}, g_{\text{Na}}, g_{\text{K}})$ to locate tonic spiking versus phasic onset or quiescence.
2. **Washout Trap After Entering Stable Equilibrium**: Dragging `MorphogenesisTool` sliders into a stable homogeneous regime decayed spatial perturbations to uniform equilibrium ($\operatorname{Var}(u) \to 0$). Returning sliders into the Turing island afterwards produced zero pattern growth because reaction-diffusion instability requires non-zero spatial perturbation modes around $(u^*, v^*) = (a + b, b / (a + b)^2)$.
3. **Frame-Budget & Zero-Allocation Constraints**: Progressive coarse-to-fine rendering (`[8, 4, 2, 1]`) previously existed only inside `FractalRunner` ([`math_explorer_gui/src/tabs/chaos/fractals/runner.rs`](../../math_explorer_gui/src/tabs/chaos/fractals/runner.rs)). Generalizing 2D parameter cartography across native threads and `wasm32-unknown-unknown` cooperative frames requires `8ms` time-sliced execution (`PlatformInstant`), mid-pass `AtomicU64` cancellation, zero heap allocations inside `VerifiedEngine::run_verified`, bounded state persistence (`ToolStateBounds::DEFAULT`), and WCAG 2.2 AA `ThemeMode::HighContrast` (`>= 3.0:1`) compliance.

## Decision
1. **Reusable Progressive 2D Parameter Atlas Engine ([`math_explorer_gui/src/async_sim/atlas/`](../../math_explorer_gui/src/async_sim/atlas/mod.rs))**:
   - Define `RegimeCartographer`, `AtlasAxisSpec`, `AtlasAxisPair`, and `AtlasCell` in [`math_explorer_gui/src/async_sim/atlas/mod.rs`](../../math_explorer_gui/src/async_sim/atlas/mod.rs) resolving axis bounds directly from `TheoryDescribable::theory_parameters()`.
   - Implement `AtlasRunner` in [`math_explorer_gui/src/async_sim/atlas/runner.rs`](../../math_explorer_gui/src/async_sim/atlas/runner.rs) on `BackgroundWorker<AtlasRunner>` executing progressive `[8, 4, 2, 1]` block-stride passes capped at `128 x 128` pixels (`MAX_ATLAS_SIDE = 128`), reusing coarse grid samples across finer passes, checking `AtomicU64` generation tokens and `ATLAS_SLICE_BUDGET` (`8ms` via `PlatformInstant::now()`) every 16 samples, and preallocating pixel/cell scratch buffers outside `step()`.
   - Implement lazy-worker `ParameterAtlasController` and interactive `egui_plot::Plot` overlays in [`math_explorer_gui/src/async_sim/atlas/controller.rs`](../../math_explorer_gui/src/async_sim/atlas/controller.rs) and [`math_explorer_gui/src/async_sim/atlas/ui.rs`](../../math_explorer_gui/src/async_sim/atlas/ui.rs) with `PlotImage`, optional threshold contours (`Line`), active `(p1, p2)` crosshair, hover/keyboard coordinate tooltips, click/Enter parameter teleportation, WAI-ARIA `TwinSlotLiveRegion` announcements, and `heatmap_color_high_contrast` (`>= 3.0:1` on `#000000`).
2. **Flagship Domain Cartographers & Washout Auto-Reseeding**:
   - **Morphogenesis** ([`math_explorer_gui/src/tabs/morphogenesis/atlas.rs`](../../math_explorer_gui/src/tabs/morphogenesis/atlas.rs), [`runner.rs`](../../math_explorer_gui/src/tabs/morphogenesis/runner.rs)): Classify `Stable Washout`, `Turing Pattern`, `Bulk Hopf Oscillation`, and `Euler CFL Unstable` across `(a, b)`, `(d_v, dt)`, and `(d_u, d_v)`. Detect washed-out grids (`grid_u_variance(u) < 1e-8`) when parameters transition into a pattern-forming regime and automatically re-seed deterministic perturbations (`SimpleRng::new(12345)`) around $(a + b, b / (a + b)^2)$.
   - **SIR Epidemiology** ([`math_explorer_gui/src/tabs/epidemiology/sir/atlas.rs`](../../math_explorer_gui/src/tabs/epidemiology/sir/atlas.rs), [`sir.rs`](../../math_explorer_gui/src/tabs/epidemiology/sir.rs)): Wire `calculate_final_size` into a copyable `Final Outbreak Size (S_∞ Solver)` scalar readout and a zero-allocation `(beta, gamma)` / `(beta, I0)` outbreak fraction atlas with an analytical `R₀ = 1` threshold contour.
   - **Hodgkin-Huxley** ([`math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs`](../../math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs), [`math_explorer_gui/src/async_sim/unified/atlas.rs`](../../math_explorer_gui/src/async_sim/unified/atlas.rs)): Extend `UnifiedModel` and `UnifiedSimTool<M>` with optional parameter-atlas hooks and implement `HodgkinHuxleyCartographer` reusing `HodgkinHuxleyModel::derivative` with preallocated `HodgkinHuxleyParameters` to classify `Quiescent`, `Single Spike`, and `Tonic Firing` across `(i_ext, g_na)` and `(i_ext, g_k)` with zero heap allocations.

## Consequences
- **Positive**: Users see live 2D regime boundaries, CFL stability cliffs, $R_0 = 1$ tipping lines, and spiking islands at coarse `8x` resolution within a single slice, refining smoothly to `1x` while supporting click-to-teleport and keyboard exploration.
- **Positive**: `MorphogenesisTool` recovers automatically from washed-out equilibria when entering the Turing island without requiring a manual Reset.
- **Neutral**: Workspace `.mws` and URL preset payloads stay compact within `ToolStateBounds::DEFAULT` because only `atlas_visible` and non-default `atlas_axes` keys are serialized; raster buffers are regenerated progressively on demand.
