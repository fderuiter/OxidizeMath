# ADR 20261123: Unified 2D Scalar-Field Procedural Export Pipeline

## Status
Accepted (extends [ADR 0016](0016-delete-unreferenced-boundary-conditions.md), [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), and [ADR 20261123](20261123-fft-lenia-engine-and-gray-scott-kinetics.md))

## Context
Nine of the ten `export_raster_image()` simulation tools in [`math_explorer_gui/src/framework/export_figure.rs`](../../math_explorer_gui/src/framework/export_figure.rs) previously quantized double-precision `f64` fields down to 8-bit `egui::ColorImage` bitmaps before figure export. Consequently, SVG exports serialized embedded base64 PNG `<image>` tags instead of continuous pen-plotter `<path>` geometry or crisp vector lattice cells, PNG exports hardcoded 8-bit RGBA channels (`png::BitDepth::Eight`) with `16.0 * scale` border padding in [`egui_plot/src/export_primitives/raster.rs`](../../egui_plot/src/export_primitives/raster.rs), `MarchingSquares2D` in [`crates/pure_math/src/pure_math/analysis/pde/wave_2d/particles_and_contours.rs`](../../crates/pure_math/src/pure_math/analysis/pde/wave_2d/particles_and_contours.rs) emitted only disconnected `field == 0.0` segments, and 2D finite-difference reaction-diffusion operators in [`crates/domain_biology/src/biology/diffusion/fd2d/mod.rs`](../../crates/domain_biology/src/biology/diffusion/fd2d/mod.rs) supported only zero-flux `NeumannBoundary` edges rather than toroidal periodic tiling.

## Decision
1. **Zero-Allocation Toroidal Periodic Diffusion (`pure_math` & `domain_biology`)**:
   - Add `FusedStencilStepper::step_2d_coupled_periodic` in [`crates/pure_math/src/pure_math/analysis/pde/fused_stepper.rs`](../../crates/pure_math/src/pure_math/analysis/pde/fused_stepper.rs) with allocation-free toroidal index wrap-around under `#[verified_engine::verified]`.
   - Introduce `BoundaryMode::{Neumann, Periodic}` and `PeriodicBoundary` across [`FiniteDifference2D`](../../crates/domain_biology/src/biology/diffusion/fd2d/mod.rs) and [`MaskedFiniteDifference2D`](../../crates/domain_biology/src/biology/diffusion/fd2d/mask.rs) so `SchnakenbergKinetics` and `GrayScottKinetics` in [`MorphogenesisTool`](../../math_explorer_gui/src/tabs/morphogenesis/tool.rs) tile seamlessly alongside [`LeniaTool`](../../math_explorer_gui/src/tabs/morphogenesis/lenia/mod.rs) and [`IsingModelTool`](../../math_explorer_gui/src/tabs/solid_state/ising.rs).
2. **Asymptotic-Decider Marching Squares & Stitched Contour Chains (`pure_math`)**:
   - Add [`contour_stitch.rs`](../../crates/pure_math/src/pure_math/analysis/pde/wave_2d/contour_stitch.rs) and `MarchingSquares2D::extract_stitched_chains` supporting arbitrary iso-thresholds, active-cell obstacle masks, bilinear saddle-point disambiguation (`f00 * f11 - f10 * f01` on cases `5` and `10`), and quantized endpoint welding into open and closed [`ContourChain`](../../crates/pure_math/src/pure_math/analysis/pde/wave_2d/contour_stitch.rs) polylines while keeping the per-frame `extract_zero_contours` path zero-allocation.
3. **Contour SVG Primitives, Seamless Tiles, 16-Bit Heightmaps, and PBR Normal Maps (`egui_plot`)**:
   - Add `ExportPrimitive::ContourPath` in [`egui_plot/src/export_primitives/mod.rs`](../../egui_plot/src/export_primitives/mod.rs), serializing `<g data-iso-level="..."><path d="M ... L ... [Z]"/></g>` elements in [`egui_plot/src/export_primitives/svg.rs`](../../egui_plot/src/export_primitives/svg.rs).
   - Extend `ExportOptions` in [`egui_plot/src/export.rs`](../../egui_plot/src/export.rs) with `#[serde(default)]` fields (`seamless_tile`, `contour_levels`, `normal_strength`), bypassing `16.0 * options.scale` border padding when `seamless_tile` is enabled.
   - Add [`egui_plot/src/scalar_export.rs`](../../egui_plot/src/scalar_export.rs) providing big-endian `png::BitDepth::Sixteen` grayscale heightmap encoding (`encode_heightmap_png_16bit`) and central-difference tangent-space normal-map PNG encoding (`encode_normal_map_png`) with optional toroidal edge wrap-around.
4. **Framework `ScalarField2D` Contract Across All 10 Raster Tools (`math_explorer_gui`)**:
   - Add [`ScalarField2D`](../../math_explorer_gui/src/framework/export_scalar_field.rs) (`ScalarFieldTopology::Continuous` and `ScalarFieldTopology::DiscreteLattice`), `InteractiveTool::export_scalar_field_2d`, `ExportFormat::{HeightmapPng, NormalMapPng}`, and modal/toolbar controls in [`egui_plot/src/export_modal.rs`](../../egui_plot/src/export_modal.rs) and [`math_explorer_gui/src/framework/export_ui.rs`](../../math_explorer_gui/src/framework/export_ui.rs).
   - Wire continuous `f64` scalar fields on `MorphogenesisTool`, `LeniaTool`, `ChladniWaveTankTool`, `FractalViewer` (evaluating smooth escape-time fields at target modal dimensions up to `MAX_EXPORT_DIMENSION`), `IsingModelTool`, `DoseCalculationTool`, `LatticeBoltzmannTool`, and `MriKSpaceTool`, and wire row-run-merged crisp `<rect shape-rendering="crispEdges">` discrete lattices on `PrimeSpiralWidget` and `AttentionMapsTool`.

## Consequences
- **Positive**: All 10 2D raster-exporting tools emit pure vector `<path>` or `<rect>` SVGs with zero embedded base64 PNG `<image>` fallbacks, unpadded 1:1 seamless tiles, 16-bit (`0..=65535`) displacement heightmaps, and tangent-space PBR normal maps on both desktop and `wasm32-unknown-unknown` within existing WebAssembly bundle budgets.
- **Positive**: Hot simulation loops (`step_2d_coupled_periodic`, `extract_zero_contours`) retain zero dynamic heap allocations under `VerifiedAllocator`, while `TwinSlotLiveRegion` announces every deferred export completion.
- **Neutral**: Floating-point OpenEXR/TIFF encoders, multi-material G-code planners, and 3D volumetric NIfTI exports remain out of scope.
