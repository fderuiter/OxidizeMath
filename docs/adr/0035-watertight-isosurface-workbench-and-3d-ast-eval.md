# ADR 0035: Watertight Isosurface Workbench, Padded Box-SDF Sampling, and Zero-Allocation 3D AST Evaluation

## Status
Accepted (extends [ADR 0025](0025-rolling-slice-edge-cache-marching-cubes.md) and [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md))

## Context
[`crates/domain_applied/src/applied/isosurface/marching_cubes.rs`](../../crates/domain_applied/src/applied/isosurface/marching_cubes.rs) implements Marching Cubes over `VoxelGrid` using the rolling `SliceEdgeCache` introduced in [ADR 0025](0025-rolling-slice-edge-cache-marching-cubes.md), yet three gaps prevented interactive implicit solid modeling and 3D-printable mesh export in `math_explorer_gui`:
1. **No Zero-Allocation 3D Scalar Evaluator or Binary CSG Primitives**: [`crates/math_commons/src/ast/eval.rs`](../../crates/math_commons/src/ast/eval.rs) provided `Expr::eval` (1D `x`) and `Expr::eval_2d` (2D `x, y`), while [`crates/math_commons/src/ast/expr.rs`](../../crates/math_commons/src/ast/expr.rs) restricted `Func` to 14 unary functions, omitting binary signed-distance operators (`min`, `max`, `atan2`) needed for constructive solid geometry (CSG) and cylindrical/toroidal fields.
2. **Open Boundary Half-Edges and Exact-Zero Corner Collapses**: Raw `MarchingCubes::extract` terminates at outer grid faces without closing clipped interiors (leaving `546` unpaired boundary half-edges on an unpadded `32^3` Gyroid and `96` on a clipped sphere), and snapping exact-zero corner values (`|threshold - v| < 1e-6`) produces zero-area degenerate triangles when multiple cube edges collapse onto a single corner vertex.
3. **CLI-Only Isosurface Pipeline and Text-Only Browser Export**: `extract_isosurface` had zero callers in `math_explorer_gui`, [`crates/oxidize_core/src/mesh/export.rs`](../../crates/oxidize_core/src/mesh/export.rs) exported Wavefront `.obj` strings without a binary `.stl` serializer, and [`math_explorer_gui/src/web_io.rs`](../../math_explorer_gui/src/web_io.rs) only dispatched UTF-8 string payloads rather than raw binary byte buffers.

## Decision
1. **Binary AST Functions and Zero-Allocation `Expr::eval_3d`**:
   - Add `Func::{Min, Max, Atan2}` and `Func::arity(&self) -> usize` in [`crates/math_commons/src/ast/expr.rs`](../../crates/math_commons/src/ast/expr.rs), restricting unparenthesized prefix calls (`sin x`) in [`crates/math_commons/src/ast/parser.rs`](../../crates/math_commons/src/ast/parser.rs) to unary functions (`arity() == 1`) and formatting `\min`, `\max`, and `\mathrm{atan2}` in [`crates/math_commons/src/ast/latex.rs`](../../crates/math_commons/src/ast/latex.rs).
   - Add `Expr::eval_3d(x, y, z, params)` in [`crates/math_commons/src/ast/eval.rs`](../../crates/math_commons/src/ast/eval.rs) with stack-only recursion and ASCII case-insensitive binding for `x`, `y`, and `z`, guaranteeing `0` dynamic heap allocations across `64^3` (`262,144`) evaluations under `VerifiedAllocator`.
2. **Cell-Centered Box-SDF Padding and Slab Offsetting (`manifold.rs`)**:
   - Introduce [`crates/domain_applied/src/applied/isosurface/manifold.rs`](../../crates/domain_applied/src/applied/isosurface/manifold.rs) with `IsosurfaceMode::{Solid, Sheet { thickness }}`, `WatertightGridConfig`, `sample_watertight_grid`, and `analyze_mesh_manifold`, capped at `64^3` synchronous interior samples (`66^3` padded).
   - Sample interior voxels at cell centers `min + (i - 0.5) * step` (`i = 1..=N`), intersect scalar fields with the axis-aligned bounding-box SDF (`max(field_sdf, box_sdf)`), surround the domain with a 1-voxel positive exterior halo (`i = 0` and `i = N + 1`), and nudge interior near-zero values (`|v| < 2.5e-6`) outside `Point3D::EPSILON` so `extract_isosurface(&grid, 0.0)` emits watertight 2-manifolds (`0` open boundary half-edges, `0` degenerate triangles, `3 * triangles == 2 * undirected_edges`) without evaluating user formulas outside `[min_bounds, max_bounds]`.
3. **Binary `.stl` Serializer, Byte Save Dialogs, and `IsosurfaceTab`**:
   - Add `export_mesh_to_binary_stl` in [`crates/oxidize_core/src/mesh/export.rs`](../../crates/oxidize_core/src/mesh/export.rs) emitting standard `84 + 50 * triangle_count` little-endian binary STL buffers alongside `export_mesh_to_obj_string`.
   - Add `spawn_save_as_bytes_dialog` and `spawn_save_direct_bytes` in [`math_explorer_gui/src/web_io_bytes.rs`](../../math_explorer_gui/src/web_io_bytes.rs) bridging native `rfd` file dialogs and WebAssembly `Blob` downloads.
   - Expose `IsosurfaceTab` (`#tab=isosurface`, `applied` feature) and `IsosurfaceTool` under [`math_explorer_gui/src/tabs/isosurface/`](../../math_explorer_gui/src/tabs/isosurface/mod.rs), reusing `MathExpressionInputBar`, `Camera3D::rotate_to_camera_space`, `Camera3D::project`, and `Plot3DViewport` with AccessKit canvas focus, polite ARIA live announcements, and `PlatformInstant` latency telemetry.

## Consequences
- **Positive**: TPMS lattices (Gyroid, Schwarz P, Schwarz D), algebraic surfaces, and CSG signed-distance equations evaluate with `0` per-voxel heap allocations and extract into closed 2-manifold `.stl` and `.obj` solids directly in desktop and WebAssembly builds.
- **Positive**: Zero external dependencies are added, keeping the Brotli-compressed WebAssembly bundle well within the `3 MiB` budget and preserving existing parametric/point-cloud tools (`SurfaceViewer`, `AttractorPlotter`, `CrystalViewer`, `GaussianSplattingTool`) untouched.
- **Negative / Trade-offs**: Synchronous grid sampling is bounded to `64^3` interior voxels (`262,144` evaluations) to preserve interactive frame pacing on single-threaded WebAssembly; higher-resolution chunked or worker-offloaded extraction remains future work.
