# ADR 0044: Unify Build-Time and Runtime Traceability Scanning via `TraceabilityEngine`

## Status
Accepted (extends [ADR 0007](0007-consolidate-workspace-discovery.md), [ADR 0011](0011-ast-citation-binding-and-cli-check-enforcement.md), [ADR 0027](0027-build-rerun-directives-and-cargo-cache.md), and [ADR 0032](0032-precomputed-traceability-manifest-and-wasm-vfs-subpaths.md))

## Context
1. **Duplicated Build-Time Scanners and Serializers**: [`math_explorer_gui/build_snapshot.rs`](../../math_explorer_gui/build_snapshot.rs) and `math_explorer_gui/build_snapshot_scan.rs` reimplemented ~700 lines of workspace directory discovery, Rust comment/string stripping, `mod` declaration lexing, `[cite:...]` / `embed_theory` substring extraction, `traceability.toml` parsing, semantic integrity heuristics, and manual JSON string escaping that already lived in [`crates/oxidize_core/src/traceability.rs`](../../crates/oxidize_core/src/traceability.rs).
2. **Zeroed AST Metrics and Parity Drift**: Because the custom build-script scanner bypassed `syn` and [`crates/oxidize_core/src/ast_visitor.rs`](../../crates/oxidize_core/src/ast_visitor.rs), `traceability_manifest.json` hardcoded seven [`TraceabilityReport`](../../crates/oxidize_core/src/traceability.rs) fields (`unverified_modules`, `total_funcs`, `total_asserts`, `verified_funcs`, `verified_asserts`, `invalid_tiers`, and `vacuous_bypasses`) to empty/zero defaults and approximated `semantic_integrity_status` without checking `#[verified]` function attributes.
3. **Unscoped Path-Dependency Tab Discovery**: [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) included `path_utils.rs` via `#[path = ...]` and scanned every line containing `path = "` in [`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml) rather than scoping `ExplorerTab` discovery to runtime `[dependencies]`.

## Decision
1. **Consolidate Workspace Discovery and Manifest Types in `oxidize_core::traceability`**:
   - Move `VerificationCertificate` and `TraceabilityManifestPayload` into [`crates/oxidize_core/src/traceability/manifest.rs`](../../crates/oxidize_core/src/traceability/manifest.rs) and re-export them from `oxidize_core::traceability` and [`math_explorer_gui/src/tabs/traceability/web_snapshot.rs`](../../math_explorer_gui/src/tabs/traceability/web_snapshot.rs).
   - Add `TraceabilityEngine::discover_workspace_dirs` and `TraceabilityEngine::scan_workspace` in [`crates/oxidize_core/src/traceability.rs`](../../crates/oxidize_core/src/traceability.rs) and delegate [`math_explorer_gui/src/tabs/traceability/scanner.rs`](../../math_explorer_gui/src/tabs/traceability/scanner.rs) (`execute_workspace_scan`) to `scan_workspace`.
2. **Execute `TraceabilityEngine` in `math_explorer_gui/build.rs` via `[build-dependencies]`**:
   - Declare `oxidize_core`, `futures`, and `serde_json` under `[build-dependencies]` in [`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml), scope `scan_cargo_toml_deps` in [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) to `[dependencies]`, and import `oxidize_core::path_utils` directly.
   - Delete `math_explorer_gui/build_snapshot_scan.rs` and replace custom parsers/serializers in [`math_explorer_gui/build_snapshot.rs`](../../math_explorer_gui/build_snapshot.rs) with a read-only `BuildSnapshotVfs` (`VirtualFileSystem` rooted at `..`) that emits deduplicated forward-slash `cargo:rerun-if-changed` directives only for existing paths, runs `TraceabilityEngine::scan_workspace`, sorts JSON keys via `serde_json::to_value`, and writes `traceability_manifest.json` across `OUT_DIR` and Cargo target directories.
3. **Enforce Full `TraceabilityReport` Parity**:
   - Guard `#[verified]` and `#[embed_theory]` attribute matching in [`crates/oxidize_core/src/ast_visitor.rs`](../../crates/oxidize_core/src/ast_visitor.rs) (`AstVisitor::process_fn_attrs`) so `#[doc = "..."]` Rustdoc examples on procedural macro entrypoints extract `[cite:...]` tags without registering synthetic `embed_theory` modules or verified function counts.
   - Update [`math_explorer_gui/src/tabs/traceability/snapshot_tests.rs`](../../math_explorer_gui/src/tabs/traceability/snapshot_tests.rs) to assert full `TraceabilityReport` equality between `OUT_DIR/traceability_manifest.json` and live `execute_workspace_scan`, including non-zero `syn` AST function and assertion counts.

## Consequences
- **Positive**: Removes ~700 lines of duplicate Rust/TOML/JSON parsing logic while guaranteeing identical `TraceabilityReport` outputs across build-time web/desktop snapshots and live native scans.
- **Positive**: Preserves Cargo incremental cache validity by emitting forward-slash `cargo:rerun-if-changed` directives strictly for existing files and directories.
- **Neutral**: Host-only `[build-dependencies]` leave WebAssembly runtime dependencies unchanged within the 3 MiB compressed bundle budget, and [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json) records the new `oxidize_core::traceability` public items.
