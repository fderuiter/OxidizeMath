# ADR 0045: Shared `RasterBrushCanvas`, Pre-Allocation RLE `base64url` Spatial Masks, and Live 2D Field Sculpting

## Status
Accepted (extends [ADR 0012](0012-background-simulation-worker-offload.md), [ADR 0022](0022-unify-preset-state-serialization.md), [ADR 0032](0032-high-contrast-focus-selection-and-raster-tokens.md), and [ADR 0033](0033-wasm32-browser-tests-and-playwright-ci-smoke-gate.md))

## Context
Four flagship 2D raster simulations in `math_explorer_gui`—Lattice-Boltzmann fluid dynamics (`UnifiedSimTool<LbmUnified>`), Turing reaction-diffusion (`MorphogenesisTool`), the 2D Ising model (`IsingModelTool`), and tabular Q-learning (`GridWorldTool`)—prevented interactive physical experimentation due to four architectural limitations:
1. **Passive Canvases and `round()` Cell Drift**: `MorphogenesisTool`, `IsingModelTool`, and `GridWorldTool` allocated canvases with `Sense::hover()`, offering zero pointer or keyboard sculpting. `UnifiedSimTool` used `Sense::drag()`, ignored single clicks, applied `.round()` to fractional cell coordinates (shifting brushstrokes by `+0.5` cells and clamping right/bottom edges inconsistently), inverted Y-axis brush coordinates when `flip_y(true)` was active, and skipped intermediate cells during fast pointer drags.
2. **Ephemeral Obstacles and Unbounded JSON Array Caps**: Painted LBM obstacles lived only inside the transient worker thread and vanished on `Reset`, `save_state`, preset export, or URL sharing. Naive per-cell JSON arrays on `128x128` (`16,384` elements) or `200x80` (`16,000` elements) grids approach or exceed `ToolStateBounds::max_array_len` (`16,384`) and overflow `URL_JSON_BOUNDS` (`4,096` decoded bytes).
3. **Uniform Domain Solvers**: `SchnakenbergSolver` evaluated spatially homogeneous `(a, b)` feed/kill rates across the entire domain, `SpinLattice` lacked pinned boundary sites during Metropolis sweeps, and `GridWorldEnv` hardcoded hazards without impassable wall obstacles.
4. **WCAG 2.2 AA Keyboard Operability**: Pointer-only brush painting violated WCAG 2.2 SC 2.1.1 (Keyboard) and SC 2.1.2 (No Keyboard Trap) unless paired with a focusable keyboard reticle, arrow-key navigation, and non-trapping `Tab` / `Shift+Tab` / `Escape` focus traversal.

## Decision
1. **Shared `RasterBrushCanvas` Widget and Integer Bresenham Stencil Engine**:
   - Introduce [`math_explorer_gui/src/framework/raster_brush/`](../../math_explorer_gui/src/framework/raster_brush/mod.rs) (`bresenham.rs`, `stencils.rs`, `rle.rs`, `canvas.rs`) providing an aspect-locked `Sense::click_and_drag()` canvas with `floor()` cell mapping (`((rel * dim) as isize).clamp(0, dim - 1)`), explicit `flip_y` coordinate inversion, continuous integer Bresenham line interpolation across drag frames, configurable brush radius, geometric stencils (`Freehand`, `FilledCircle`, `LineSegment`, `NacaAirfoil`, `VenturiNozzle`), and `BilateralY` / `Radial4` symmetry transforms.
   - Integrate WCAG 2.2 AA keyboard reticles across all four canvases using `lock_canvas_arrow_keys` (locking only arrow keys while leaving `Tab`, `Shift+Tab`, and `Escape` unlocked), `Space` to stamp, `Backspace`/`Delete` to erase, `paint_canvas_focus_ring` for high-contrast focus halos, `register_canvas_accessibility` for AccessKit labeling, and `announce_live_status` polite readouts.
2. **Two-Pass Pre-Allocation RLE `base64url` Mask Codec**:
   - Encode 2D `u8` cell masks as compact `RMW1` binary headers (`width: u16`, `height: u16`) followed by `(value: u8, run_len: uleb128)` pairs encoded with `url_state::encode_base64url`.
   - Enforce a zero-heap-allocation validation pass (`verify_rle_stream_without_grid_alloc`) that checks `MAX_RLE_ENCODED_LEN`, header magic, exact `(expected_width, expected_height)` dimensions, `MAX_RLE_CELLS` (`65,536`), `palette_max`, and exact run-length sum (`total == width * height`) *before* allocating `Vec<u8>`, keeping serialized tool states well within `ToolStateBounds` and `4,096`-byte URL share budgets.
3. **Zero-Allocation Spatial Domain Extensions & Worker Synchronization**:
   - Extend `ReactionKinetics` with a backward-compatible defaulted `reaction_at(&self, index: usize, u: f64, v: f64)` method and add preallocated `SpatialSchnakenbergKinetics` in [`crates/domain_biology/src/biology/morphogenesis/spatial_reaction.rs`](../../crates/domain_biology/src/biology/morphogenesis/spatial_reaction.rs) so `SchnakenbergSolver` steps spatially heterogeneous `(a, b)` masks with zero hot-path allocations.
   - Add a preallocated `pinned: Vec<bool>` mask to `SpinLattice` in [`crates/domain_physics/src/physics/stat_mech/ising.rs`](../../crates/domain_physics/src/physics/stat_mech/ising.rs) skipped during `metropolis_step` and `evolve`, and add `walls: Vec<GridState>` blocking transitions in `GridWorldEnv::step` in [`crates/domain_ai/src/ai/reinforcement_learning/grid_world.rs`](../../crates/domain_ai/src/ai/reinforcement_learning/grid_world.rs), both verified under `VerifiedEngine::run_verified`.
   - Add `SimCommand::ApplyBrushCells(Vec<(usize, usize, u8)>)` to `async_sim` workers (`LbmUnified`, `MorphogenesisRunner`, `IsingRunner`) and persist RLE masks across `save_state`, `try_load_state`, `reset_simulation`, URL fragments, and four sculpted `StarterPresetMetadata` presets (`lbm_airfoil_wake`, `turing_spot_stripe_mask`, `ising_pinned_domain_wall`, `grid_world_labyrinth_maze`).

## Consequences
- **Positive**: Users can sculpt wind-tunnel airfoils and Venturi nozzles in LBM, hybrid spot-stripe morphogenesis masks, pinned Ising spin domain walls, and Bellman Q-learning labyrinths via mouse, touch, or keyboard without losing sculpted geometry on reset or URL sharing.
- **Positive**: Pre-allocation RLE validation prevents untrusted URL payloads from triggering oversized allocations, and all domain inner loops preserve strictly zero dynamic allocations under `VerifiedAllocator`.
- **Neutral**: Unrelated 1D plot and 3D viewport simulations retain their specialized `InteractiveTool::show_inside` implementations without migration overhead.
