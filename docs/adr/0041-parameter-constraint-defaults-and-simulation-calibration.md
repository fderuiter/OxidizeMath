# ADR 0041: Calibrated `ParameterConstraint` Defaults and Domain Simulation Calibration

## Status
Accepted (extends [ADR 0007](0007-reflective-ui-fallback-constraints.md), [ADR 0034](0034-harden-verification-macros-and-facade-reexports.md), and [ADR 0035](0035-kelly-net-odds-seeded-rng-and-paradox-labs.md))

## Context
Reflective UI initialization, recovery resets, and non-finite JSON state sanitization previously synthesized parameter defaults solely from the arithmetic midpoint `0.5 * (min + max)` whenever discrete choices were absent. Across physically asymmetric parameter ranges, midpoint initialization and uncoupled UI metadata caused miscalibrated defaults and solver mismatches across nine interactive tools:

1. **Midpoint Miscalibration & Duplicate Inlets**: [`HodgkinHuxleyUnified`](../../math_explorer_gui/src/tabs/neuroscience/hodgkin_huxley.rs) initialized leak conductance $g_L = 2.5\text{ mS/cm}^2$ and stimulus $I_{\text{ext}} = 25.0\,\mu\text{A/cm}^2$ instead of physiological $(g_{Na}, g_K, g_L, I_{\text{ext}}) = (120, 36, 0.3, 10)$, flatlining action potentials. [`LbmUnified`](../../math_explorer_gui/src/tabs/fluid_dynamics/lattice_boltzmann.rs) initialized $\nu \approx 0.2517$ ($Re \approx 4$) instead of $\nu = 0.02$ ($Re = 50$) and applied a duplicate narrow inlet in `new()` inconsistent with `step()`. [`WaveSimulatorTool`](../../math_explorer_gui/src/tabs/quantum/wave_sim/presets.rs) lacked explicit calibrated `default` metadata on `wave_parameter_constraints()`.
2. **Odds Bounds, Seed Controls, and Quantum Spin Steps**: [`BankrollGrowthTool`](../../math_explorer_gui/src/tabs/financial_math/bankroll_growth.rs) needed decimal odds bounded strictly above `1.0` (`1.01..=10.0`) via `Odds::new`, `net_profit_multiplier()` settlement, zero-division protection in `theory_description`, and an editable seed control matching `$1,650.10` geometric expectation over 100 bets. [`RandomizationTool`](../../math_explorer_gui/src/tabs/clinical_trials/randomization.rs) needed an editable seed control and baseline seed reset. [`ClebschGordanTool`](../../math_explorer_gui/src/tabs/quantum/clebsch.rs) stepped coupled $J$ and $M$ sliders by `1.0`, blocking `220 / 441` half-integer spin couplings.
3. **Boundary Singularities, Formula Drift, and Fixed Sensitivity Horizons**: [`CapacityFadeTool`](../../math_explorer_gui/src/tabs/battery_degradation/capacity_fade.rs) permitted $\text{DoD} = 0\%$ (`inf` cycle life) and displayed $C_0(1 - 0.3(N/N_{70})^z)$ instead of `PowerLawModel`'s exact $C(N) = 0.7^{N/N_{70}}$. [`LossLandscapeTool`](../../math_explorer_gui/src/tabs/ai/loss_landscape/presets.rs) needed explicit $\frac{1}{n}\sum (f(x_i, w, b) - y_i)^2$ MSE display, and [`SirTool`](../../math_explorer_gui/src/tabs/epidemiology/sir.rs) integrated local sensitivity over a hardcoded 50-day window instead of `self.duration`.

## Decision
1. **Optional Calibrated Defaults on `ParameterConstraint` and `#[derive(Theory)]`**:
   - Add `pub default: Option<f64>` and `ParameterConstraint::effective_default(&self) -> f64` (falling back to `0.5 * (self.min + self.max)` when `None`) in [`crates/scientific_metadata/src/theory.rs`](../../crates/scientific_metadata/src/theory.rs).
   - Extend `#[derive(Theory)]` in [`crates/verified_engine_macros/src/theory.rs`](../../crates/verified_engine_macros/src/theory.rs) to parse optional `default = <finite_literal>` field attributes, enforce `min <= default <= max` at compile time, and emit `default: Some(...)` / `None`.
   - Propagate `effective_default()` across [`math_explorer_gui/src/framework/clamp.rs`](../../math_explorer_gui/src/framework/clamp.rs) and [`math_explorer_gui/src/async_sim/unified/tool.rs`](../../math_explorer_gui/src/async_sim/unified/tool.rs) (`new`, `ClampParameters`, `ResetParameters`), and regenerate [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json).
2. **Domain Tool Calibration**:
   - Calibrate `ParameterConstraint` defaults on `HodgkinHuxleyUnified` (`120.0, 36.0, 0.3, 10.0` firing 4 spikes in `50 ms`), `LbmUnified` (`viscosity = 0.02`, $Re = 50$, single uniform inlet), and `WaveSimulatorTool` (`dt = 0.02` on `0.001` step grid).
   - Bound `BankrollGrowthTool` decimal odds to `1.01..=10.0` via `Odds::new` with zero-division-safe `theory_description`, and add editable `seed_counter` `DragValue` + baseline seed reset controls to both `BankrollGrowthTool` and `RandomizationTool`.
   - Set `ClebschGordanTool` $J$ and $M$ slider steps to `0.5`, clamp `CapacityFadeTool` $\text{DoD} \in [1.0, 100.0]$ with exact $C(N) = 0.7^{N / N_{70}}$ theory metadata, display $\frac{1}{n}$ MSE in `LossLandscapeTool`, and integrate `SirTool::evaluate_sensitivity` over `self.duration`.

## Consequences
- **Positive**: Startup states, fault recovery resets, and non-finite JSON fallbacks honor domain-calibrated operating points without sacrificing midpoint fallback for unconstrained symmetric parameters or breaking saved `.json` / `.mws` and starter gallery presets.
- **Positive**: Interactive UI sliders, stochastic seed controls, sensitivity horizons, and LaTeX theory descriptions match underlying verified mathematical kernels across all nine tools.
