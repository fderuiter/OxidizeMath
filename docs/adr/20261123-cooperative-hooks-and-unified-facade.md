# ADR 20261123: Cooperative Tool Hooks, Instance-Scoped Cross-Tool Bus, and Unified Facade Suite

## Status
Accepted (extends [ADR 0008](0008-finite-state-guard-solver-divergence.md), [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md), [ADR 0039](0039-metric-agnostic-3d-tda-exact-z2-homology-and-chaos-mashup.md), [ADR 0040](0040-promote-zero-alloc-curve-solvers-to-math-commons.md), and [ADR 20261123](20261123-shared-simulation-topology-bus.md))

## Context
1. **GUI-Locked Sensitivity Logic**: `SensitivityEngine` resided solely inside `math_explorer_gui`, preventing headless Rust callers, `#![no_std]` + `alloc` consumers, doctests, and CLI workflows from running progressive finite-difference elasticity, wide-range tornado bounds, or deterministic Monte Carlo uncertainty propagation.
2. **Uncooperative Tool Introspection and Manual CSV Fitting**: Applied and fluid-dynamics tools lacked unified cooperative hooks for bounded per-frame sensitivity sweeps (`<= 8` model evaluations/frame) and automated bounded nonlinear regression against user-imported `egui_plot` CSV series.
3. **Overlay Traces Without Scalar KPI Deltas**: [`math_explorer_gui/src/framework/trace_overlay.rs`](../../math_explorer_gui/src/framework/trace_overlay.rs) overlaid historical `(x, y)` curves without tabular scalar KPI baseline comparisons or CSV KPI export.
4. **Typed Cross-Pane Envelope Routing**: Alongside [`SharedSimulationBus`](../../math_explorer_gui/src/app/sim_bus.rs) for background worker snapshots and CSR topologies, interactive tools needed an instance-scoped `CrossToolBus` on `SimulationFramework` for structured `PointCloud3D`, `TimeSeries2D`, and `ParameterSet` envelopes with zero process-global `OnceLock` or `static` state.
5. **Facade Ergonomics and Benchmark Coverage**: `math_explorer::prelude` and `math_explorer/benches/` covered only a narrow slice of the umbrella crate, and headless users lacked an opt-in CLI entry point for sensitivity and curve calibration.

## Decision
1. **Hoist `SensitivityEngine` into `math_commons::sensitivity`**:
   - Implement `#![no_std]` + `alloc` compatible [`crates/math_commons/src/sensitivity/mod.rs`](../../crates/math_commons/src/sensitivity/mod.rs), [`finite_diff.rs`](../../crates/math_commons/src/sensitivity/finite_diff.rs), [`tornado.rs`](../../crates/math_commons/src/sensitivity/tornado.rs), and [`monte_carlo.rs`](../../crates/math_commons/src/sensitivity/monte_carlo.rs) (including gesture-deferred sweep suspension via `defer_for_gesture`, baseline-hinted finite differencing via `compute_with_baseline`, and synchronous instruction-budget clamping via `compute_budgeted_with_baseline`), re-exported through [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs), [`math_explorer/src/prelude.rs`](../../math_explorer/src/prelude.rs), and all `__doctest_facade` modules.
   - Bound `step_tornado` / `step_tornado_slice` and `step_monte_carlo` / `step_monte_carlo_slice` to `<= 8` model evaluations per call, using explicit `u64`-seeded `SplitMix64` Box-Muller draws, Welford streaming mean/variance, quickselect `p05`/`p50`/`p95` quantiles, and zero heap allocations in pre-warmed hot loops (verified in [`crates/math_commons/tests/verified_sensitivity.rs`](../../crates/math_commons/tests/verified_sensitivity.rs)).
2. **Wire Cooperative Sensitivity and Bounded CSV Calibration Hooks**:
   - Extend `InteractiveTool` ([`math_explorer_gui/src/framework/mod.rs`](../../math_explorer_gui/src/framework/mod.rs), [`cooperative_hooks.rs`](../../math_explorer_gui/src/framework/cooperative_hooks.rs), [`calibration.rs`](../../math_explorer_gui/src/framework/calibration.rs)) and `UnifiedSimTool` ([`math_explorer_gui/src/async_sim/unified/controls.rs`](../../math_explorer_gui/src/async_sim/unified/controls.rs), [`sensitivity.rs`](../../math_explorer_gui/src/async_sim/unified/sensitivity.rs)) with cooperative sensitivity/tornado/Monte Carlo stepping and logistic-bounded `levenberg_marquardt_numeric` (`MAX_FIT_PARAMS = 6`) CSV calibration backed by `FiniteStateGuard` snapshot rollback.
   - Expose `PlotMemory::imported_datasets` ([`egui_plot/src/lib.rs`](../../egui_plot/src/lib.rs)) through `SimulationFramework::end_plot_scope` ([`math_explorer_gui/src/framework/plot_persistence.rs`](../../math_explorer_gui/src/framework/plot_persistence.rs)), and wire observables and calibration across `LbmUnified`, `BankrollGrowthTool`, `PharmacokineticsTool`, `SampleSizeCalculatorTool`, `ReplicatorDynamicsTool`, `Glicko2TournamentTool`, `CapacityFadeTool`, and `LifetimeEstimatorTool`.
3. **Add `ScenarioKpi` Comparison Table and CSV Export**:
   - Extend `TraceSnapshot` ([`math_explorer_gui/src/framework/trace_overlay.rs`](../../math_explorer_gui/src/framework/trace_overlay.rs), [`kpi.rs`](../../math_explorer_gui/src/framework/trace_overlay/kpi.rs), [`ui.rs`](../../math_explorer_gui/src/framework/trace_overlay/ui.rs)) with `#[serde(default)]` `kpis: Vec<ScenarioKpi>` while preserving `#[serde(deny_unknown_fields)]`, rendering raw values, absolute deltas, and percentage deltas against pinned baselines plus CSV export.
4. **Add Instance-Scoped `CrossToolBus` Routing Coexisting with `SharedSimulationBus`**:
   - Introduce [`math_explorer_gui/src/framework/cross_tool_bus.rs`](../../math_explorer_gui/src/framework/cross_tool_bus.rs) (`PointCloud3D`, `TimeSeries2D`, `ParameterSet`) on `SimulationFramework` and route cross-pane envelopes in [`math_explorer_gui/src/app/domain_bar.rs`](../../math_explorer_gui/src/app/domain_bar.rs) and [`cross_tool_routing.rs`](../../math_explorer_gui/src/app/cross_tool_routing.rs), bridging background `SharedSimulationBus` point-cloud snapshots into typed `CrossToolBus` envelopes with zero `static` or `OnceLock` singletons in [`vietoris_rips/handoff.rs`](../../math_explorer_gui/src/tabs/geometry_topology/vietoris_rips/handoff.rs).
5. **Expand `math_explorer::prelude`, Opt-In CLI, and Criterion Suites**:
   - Curate feature-gated numerical and domain solvers in [`math_explorer/src/prelude.rs`](../../math_explorer/src/prelude.rs), add an opt-in `cli` binary ([`math_explorer/src/bin/math_explorer.rs`](../../math_explorer/src/bin/math_explorer.rs)) with `sensitivity` and `calibrate` subcommands, and add facade-only Criterion suites in [`math_explorer/benches/`](../../math_explorer/benches/).

## Consequences
- **Positive**: Unifies `#![no_std]`-compatible headless and interactive sensitivity, uncertainty propagation, and bounded nonlinear CSV fitting with zero hot-loop allocations, deterministic `u64` seeding, synchronous instruction-budget enforcement, and instance-scoped cross-tool routing.
- **Neutral**: Adds opt-in host-only `cli` binary and Criterion benchmark targets in `math_explorer` without altering default library dependencies or WebAssembly bundle budgets.
