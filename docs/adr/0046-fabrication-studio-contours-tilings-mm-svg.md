# ADR 0046: Add 2D Marching-Squares Contours, Aperiodic Tilings, Millimeter Fabrication SVG Export, and Fabrication Studio

## Status
Accepted (extends [ADR 0024](0024-deferred-modal-exports-and-plot-primitives.md), [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md), and [ADR 0040](0040-promote-zero-alloc-curve-solvers-to-math-commons.md))

## Context
[`egui_plot/src/export_primitives`](../../egui_plot/src/export_primitives/mod.rs) and [`math_explorer_gui/src/framework/export_figure.rs`](../../math_explorer_gui/src/framework/export_figure.rs) previously exported 2D simulation fields such as Gray-Scott reaction-diffusion grids as Base64-encoded `<image>` heatmaps or fixed-pixel academic figures (`800px` × `600px` with background `<rect>` fills and axis ticks). Pen plotters (AxiDraw, NextDraw), vinyl cutters, and laser cutters (LightBurn, Inkscape) require true physical millimeter dimensions (`width="{w}mm" height="{h}mm" viewBox="0 0 {w} {h}"`), unclosed/closed vector `<path fill="none">` geometry grouped into cut and score layers (`<g id="layer-cut">` and `<g id="layer-score">`), deduplicated interior tile edges to prevent double-cutting, and ordered toolpaths that minimize rapid pen-lift travel.

## Decision
1. **2D Marching-Squares Contours, RK4 Streamlines, Path Ordering, and Flat-Run Plateau Fast-Forward in `math_commons`**:
   - Add [`crates/math_commons/src/contours`](../../crates/math_commons/src/contours/mod.rs) (re-exported via [`math_explorer::contours`](../../math_explorer/src/lib.rs)) providing linear-interpolated marching-squares iso-contour extraction (`extract_contours`, `ContourPolyline`) with center-average saddle disambiguation and endpoint stitching, bounded-step RK4 streamline tracing (`trace_streamlines`, `StreamlineParams`) with stagnation termination, and greedy nearest-neighbor endpoint-reversal path ordering (`order_polylines_nearest_neighbor`, `pen_lift_travel`).
   - Add 8-wide branchless flat-slice scanning (`Sample2D::advance_flat_slice` and `PointSeries::advance_flat_run`) in [`crates/math_commons/src/series.rs`](../../crates/math_commons/src/series.rs) and [`crates/math_commons/src/poi/extrema.rs`](../../crates/math_commons/src/poi/extrema.rs) so 200k-point plateau scans remain sub-millisecond even under unoptimized `cargo llvm-cov` coverage instrumentation.
   - Keep simulation hot loops allocation-free under `VerifiedAllocator`; contour and streamline extraction run strictly on cold export/preview paths.
2. **Aperiodic Penrose (`P2`, `P3`) and Einstein (`Hat`, `Spectre`) Tilings in `pure_math`**:
   - Add [`crates/pure_math/src/pure_math/tilings`](../../crates/pure_math/src/pure_math/tilings/mod.rs) (re-exported via [`math_explorer::pure_math::tilings`](../../math_explorer/src/lib.rs)) implementing Robinson-triangle deflation for Penrose `P2` (kite & dart) and `P3` (thick & thin rhomb) patches plus metatile substitution systems (`H`, `T`, `P`, `F` and Spectre mystic Cluster) for the Smith–Myers–Kaplan–Goodman-Strauss (2023) aperiodic monotiles, with subdivision depth capped at `6` and canonical quantized undirected segment deduplication (`deduplicate_polygon_edges`) to eliminate double-burned shared interior boundaries.
3. **1:1 Millimeter Fabrication SVG Serializer in `egui_plot`**:
   - Add [`egui_plot/src/export_primitives/fabrication_svg.rs`](../../egui_plot/src/export_primitives/fabrication_svg.rs) exposing `SheetPreset` (`A4` `210` × `297` mm, `UsLetter` `215.9` × `279.4` mm, `Custom` `20..=1200` mm), `FabricationSvgSpec`, `FabricationLayer` (`Cut` `#ff0000`, `Score` `#0000ff`), and `export_fabrication_svg` emitting clean `<svg width="{w}mm" height="{h}mm" viewBox="0 0 {w} {h}">` documents containing `<g id="layer-cut">` and `<g id="layer-score">` vector `<path fill="none">` elements with zero `<image>` or background `<rect>` tags, aspect-preserving margin scaling, and optional outer frame paths.
4. **Vector Export Hooks in `PotentialFlowTool` and `MorphogenesisTool`, plus `FabricationStudioTool`**:
   - Add [`crates/domain_physics/src/physics/fluid_dynamics/potential_flow_streamlines.rs`](../../crates/domain_physics/src/physics/fluid_dynamics/potential_flow_streamlines.rs) and wire [`MorphogenesisTool`](../../math_explorer_gui/src/tabs/morphogenesis/contours.rs) and [`PotentialFlowTool`](../../math_explorer_gui/src/tabs/fluid_dynamics/potential_flow_streamlines.rs) to emit `f64` vector `PlotPrimitive::Polyline` contours and streamlines alongside `InteractiveTool::export_custom_svg` support in [`math_explorer_gui/src/framework/export_figure.rs`](../../math_explorer_gui/src/framework/export_figure.rs).
   - Add [`FabricationStudioTool`](../../math_explorer_gui/src/tabs/geometry_topology/fabrication_studio/mod.rs) under [`GeometryTopologyTab`](../../math_explorer_gui/src/tabs/geometry_topology/mod.rs) combining all six generators, physical sheet/margin/stroke controls, 1:1 millimeter bed + dashed pen-lift preview, direct `.svg` download via `spawn_save_as_file_dialog`, three starter gallery cards, and `< 4 KiB` URL share-state round-tripping across desktop and `wasm32-unknown-unknown`.

## Consequences
- **Positive**: Users can generate, preview, share, and download fabrication-ready 1:1 millimeter vector SVGs directly in the browser or desktop app with zero new Cargo dependencies, zero network calls, and zero hot-loop allocations.
- **Positive**: Shared interior tiling edges are deduplicated automatically and nearest-neighbor toolpath ordering measurably reduces pen-lift rapid travel across multi-component patterns.
- **Neutral**: Subdivision depth (`<= 6`), grid resolution (`<= 160`), and streamline seed counts (`<= 64`) are bounded to preserve interactive client-side responsiveness on `wasm32`.
