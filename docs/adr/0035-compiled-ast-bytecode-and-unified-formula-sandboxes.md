# ADR 0035: Compiled AST Bytecode and Unified Formula Sandboxes

## Status
Accepted (supersedes [ADR 0029](0029-consolidate-ast-evaluators-and-parser-helpers.md); extends [ADR 0010](0010-animated-slider-reflective-ui.md), [ADR 0017](0017-native-ast-expression-parser-and-live-input.md), and [ADR 0026](0026-bounded-ast-height-and-iterative-traversal.md))

## Context
1. **Recursive Pointer-Chasing AST Evaluation**: `Expr::eval_fast` in `crates/math_commons/src/ast/eval.rs` recursively walked heap-allocated `Box<Expr>` nodes and performed per-sample string comparisons for constants (`pi`, `e`, `tau`, `phi`) and caller-supplied variables. Evaluating thousands of grid points per 60 FPS frame across 2D surfaces (`64x64` meshes with finite-difference Weingarten curvature stencils), loss landscapes (`35x35 x N` dataset samples), or conformal contour grids incurred pointer-chasing overhead and recursive call stacks.
2. **Single-Argument Function Grammar & Silent Unknown-Call Multiplication**: `Func` only supported unary functions, preventing piecewise and multi-argument primitives (`min`, `max`, `clamp`, `step`, `rect`, `atan2`), while unknown identifier calls such as `foo(x)` silently parsed as implicit multiplication `foo * (x)`.
3. **Underutilized Live Equation Authoring & Pole Artifacts**: `MathExpressionInputBar` was wired into only `2 / 55` (`3.64%`) registered `InteractiveTool` sandboxes (`OdeSolverTool` and `ComplexMappingTool`) without free-parameter slider synthesis, and `ComplexMappingTool` clamped non-finite conformal singularities (`1/z`, `z + a^2/z`) to `(1e6, 1e6)` instead of breaking contour polylines across poles.

## Decision
1. **Flat Postfix `CompiledExpr` Bytecode Engine**: Introduce `CompiledExpr` and `Instruction` in `crates/math_commons/src/ast/compiled.rs` (re-exported via `math_explorer::commons::ast`). Compilation resolves universal constants at compile time, assigns coordinate axes (`x`, `y`, `z`, `u`, `v`, `w`, `b`) and discovered free parameters into contiguous `u16` variable slots, verifies stack depth (`<= MAX_EVAL_DEPTH = 64`) and `Func::arity()`, and executes iteratively on a fixed `[T; MAX_EVAL_DEPTH]` stack with zero heap allocations under `VerifiedAllocator` and zero recursion frames.
2. **Multi-Arity & Piecewise Functions + Explicit `UnknownFunction` Diagnostics**: Extend `Func` with `Min`, `Max`, `Clamp`, `Step`, `Rect`, and `Atan2`, add `Func::arity()` and iterative `Expr::free_variables()`, render LaTeX macros (`\min`, `\max`, `\mathrm{clamp}`, `\mathrm{step}`, `\mathrm{rect}`, `\mathrm{atan2}`), and reject unknown `ident(...)` calls with 1-indexed `ParseError::UnknownFunction` while preserving implicit multiplication (`2x`, `k(x + 1)`).
3. **Parameterized `MathExpressionInputBar` & Transient-Edit Isolation**: Extend `MathExpressionInputBar` and `ParameterSliderBank` (`math_explorer_gui/src/framework/math_input.rs`) to compile expressions against declared coordinate axes, synthesize up to `MAX_SYNTHESIZED_PARAMS = 6` `AnimatedSlider` controls, persist parameter maps in JSON presets and `#state=` URLs, and retain the last valid `CompiledExpr` during transient syntax edits so `SimulationFramework` never triggers false `FiniteStateGuard` rollbacks.
4. **Pole Contour Splitting & Unified Custom Formula Sandboxes**: Replace `(1e6, 1e6)` clamping in `ComplexMappingTool` with discontinuity/pole polyline splitting, add `CompiledHeightfieldSurface` and `CompiledParametricSurface` implementing `ParametricSurface` in `pure_math`, and unlock custom `CompiledExpr` formulas + parameter sliders across `ComplexMappingTool`, `RiemannIntegrationTool`, `ActivationFunctionsTool`, `SurfaceViewer`, `CurvatureHeatmap`, `LossLandscapeTool`, and `ReplicatorDynamicsTool` (`8 / 55 = 14.55%` `MathExpressionInputBar` coverage alongside `OdeSolverTool`), backed by 7 new `StarterPresetMetadata` gallery cards.

## Consequences
- **Positive**: Eliminates recursive AST traversal and string-matching variable lookups in 1D, 2D, 3D, slice, and `Complex64` numerical hot loops while maintaining zero heap allocations under `VerifiedAllocator`.
- **Positive**: Expands live formula authoring and parameter-sweep exploration across complex analysis, quadrature, neural activations, differential geometry surfaces/curvature, optimization landscapes, and symbolic evolutionary game matrices with full JSON preset and `#state=` URL round-trip parity.
- **Neutral**: `OdeSolverTool` and `WaveUnified` remain untouched on the backward-compatible `MathExpressionInputBar::new` constructor, and `crates/unified_verification/api_baseline.json` is updated to record the additive `CompiledExpr`, `Instruction`, `Func`, `ParseError::UnknownFunction`, and `Compiled*Surface` public APIs.
