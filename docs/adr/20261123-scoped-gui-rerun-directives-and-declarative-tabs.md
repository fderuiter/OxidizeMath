# ADR 20261123: Scope GUI Build Rerun Directives, Unify Rust 2024 Edition, and Enforce Declarative `ExplorerTab` Contracts

## Status
Accepted (partially supersedes [ADR 0027](0027-build-rerun-directives-and-cargo-cache.md); extends [ADR 0040](0040-staged-index-snapshot-and-graph-scoped-gates.md) and [ADR 0044](0044-unify-build-time-traceability-engine.md))

## Context
1. **Over-Broad Build-Script Invalidation in `math_explorer_gui`**: Under [ADR 0027](0027-build-rerun-directives-and-cargo-cache.md) and [ADR 0044](0044-unify-build-time-traceability-engine.md), [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) walked external path dependencies (`scan_cargo_toml_deps` / `scan_external_crate`) even though zero `ExplorerTab` implementations exist outside `math_explorer_gui/src/tabs/`, and `BuildSnapshotVfs` in [`math_explorer_gui/build_snapshot.rs`](../../math_explorer_gui/build_snapshot.rs) emitted ~1,100 `cargo:rerun-if-changed=` lines covering every `.rs` source file across `../math_explorer/src` and `../crates/*`. Unconditional `fs::write` calls on `$OUT_DIR/generated_tabs.rs` and `traceability_manifest.json` also bumped file `mtime` values whenever `build.rs` reran.
2. **Centralized Tab Boilerplate and Implicit URL Slug Fallback**: Twenty-three `SimulationFramework` tabs in `math_explorer_gui/src/tabs/*/mod.rs` duplicated identical `Default` and `ExplorerTab` adapter boilerplate while [`math_explorer_gui/src/tabs/mod.rs`](../../math_explorer_gui/src/tabs/mod.rs) centralized hardcoded `academic_domain()` and `url_slug()` match tables with a `"simulation"` default fallback, and nine GUI test suites asserted brittle global tab/tool/preset count literals (`27`, `77`, `112`, `55`).
3. **Split Workspace Rust Editions**: Three crates ([`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml), [`crates/federated_registry/Cargo.toml`](../../crates/federated_registry/Cargo.toml), and [`crates/markdown_tests/Cargo.toml`](../../crates/markdown_tests/Cargo.toml)) remained on `edition = "2021"` while the other 17 workspace crates targeted `edition = "2024"`, forcing [`apps/xtask/src/staged.rs`](../../apps/xtask/src/staged.rs) to bucket staged `rustfmt` invocations by crate edition.

## Decision
1. **Unify All 20 Workspace Crates on `edition = "2024"`**:
   - Upgrade [`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml), [`crates/federated_registry/Cargo.toml`](../../crates/federated_registry/Cargo.toml), and [`crates/markdown_tests/Cargo.toml`](../../crates/markdown_tests/Cargo.toml) to `edition = "2024"` and simplify [`apps/xtask/src/staged.rs`](../../apps/xtask/src/staged.rs) to run a single `rustfmt --edition 2024` pass across staged Rust files.
2. **Scope `math_explorer_gui` Rerun Directives and Guard Output Writes**:
   - Remove external path-dependency tab scanning (`scan_cargo_toml_deps`, `scan_external_crate`, `inspect_external_rs_file`) from [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) (superseding Item 2 of [ADR 0027](0027-build-rerun-directives-and-cargo-cache.md)).
   - Restrict `cargo:rerun-if-changed=` emission across [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) and [`math_explorer_gui/build_snapshot.rs`](../../math_explorer_gui/build_snapshot.rs) strictly to `build.rs`, `build_snapshot.rs`, `Cargo.toml`, `src/tabs` (and its entries), `../traceability.toml`, `../Verification_Certificate.json`, and `../papers` (`../papers/*.tex`), emitting zero `../crates/*` or `../math_explorer/*` `.rs` directives while still computing full `TraceabilityEngine::scan_workspace` metrics via `[build-dependencies]` (`oxidize_core`).
   - Guard `$OUT_DIR/generated_tabs.rs` and all `traceability_manifest.json` destinations behind `write_if_changed` so unchanged bytes preserve filesystem `mtime` metadata.
3. **Enforce Declarative `ExplorerTab` Metadata and Dynamic Contract Invariants**:
   - Require `// @explorer_domain = "<Domain>"` and `// @explorer_slug = "<slug>"` header directives on every discovered `src/tabs/` module in [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs) (validating uniqueness and rejecting `"simulation"`), inject `EXPLORER_DOMAIN` and `EXPLORER_SLUG` module constants into `$OUT_DIR/generated_tabs.rs`, add `crate::declare_simulation_tab!`, and make `academic_domain(&self)` and `url_slug(&self)` required methods on `ExplorerTab` in [`math_explorer_gui/src/tabs/mod.rs`](../../math_explorer_gui/src/tabs/mod.rs).
   - Migrate all 23 `SimulationFramework` domain tabs to `crate::declare_simulation_tab!` and replace hardcoded global count literals across GUI contract tests with dynamic partition invariants over `instantiate_tabs()` and `inventory::iter`.

## Consequences
- **Positive**: Editing solver `.rs` files in `math_explorer` or `crates/*` no longer triggers `math_explorer_gui/build.rs` reruns, while Cargo's dependency graph still recompiles `math_explorer_gui` cleanly against updated upstream `.rlib` artifacts and no-op reruns preserve `generated_tabs.rs` and `traceability_manifest.json` modification times.
- **Positive**: Adding a new `ExplorerTab`, `InteractiveTool`, and `StarterPresetMetadata` requires zero central match-table edits in `src/tabs/mod.rs` and zero hardcoded global count bumps across unrelated contract test suites, with compile-time rejection of missing or duplicate URL slugs.
- **Neutral**: Single-binary layout (`math_explorer_gui/src/main.rs`), `traceability_manifest.json` schema parity with `web_snapshot.rs` and `scripts/finalize_web_dist.sh`, and [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json) remain unchanged.
