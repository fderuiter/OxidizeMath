# ADR 0038: Repair Consumer & Contributor Guides, Enable Full-Feature Rustdoc, and Enforce Static Documentation Gates

## Status
Accepted (extends [ADR 0005](0005-active-documentation-standard.md), [ADR 0016](0016-standardize-crate-documentation-suite.md), and [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md))

## Context
Following [ADR 0034](0034-curate-math-explorer-facade-exports-and-doctests.md), [`math_explorer/Cargo.toml`](../../math_explorer/Cargo.toml) sets `default = []` so downstream builds without domain flags compile a minimal `20`-package core, while gating all `32` `[[example]]` targets and `sorting_benchmark` behind `required-features`. However, four gaps allowed documentation and verification gates to drift from workspace manifests and trait definitions:
1. **Missing Feature and Package Flags in Guides**: Quickstart and domain guides in [`README.md`](../../README.md), [`math_explorer/examples/README.md`](../../math_explorer/examples/README.md), [`crates/domain_applied/src/applied/grpo/README.md`](../../crates/domain_applied/src/applied/grpo/README.md), and [`crates/pure_math/src/pure_math/statistics/markov/README.md`](../../crates/pure_math/src/pure_math/statistics/markov/README.md), along with consumer `[dependencies]` snippets in [`math_explorer/README.md`](../../math_explorer/README.md), `grpo/README.md`, and `markov/README.md`, omitted required `--features` or `-p pure_math` flags.
2. **Example Catalog & Paper Tooling Drift**: [`math_explorer/examples/README.md`](../../math_explorer/examples/README.md) omitted `12` of the `32` registered examples, misplaced `mmwave_setup` under Applied instead of Physics, and left an unregistered scratch file (`check_statrs.rs`) in `math_explorer/examples/`. Meanwhile, [`README.md`](../../README.md), [`apps/xtask/README.md`](../../apps/xtask/README.md), and [`apps/xtask/src/main.rs`](../../apps/xtask/src/main.rs) prescribed `Tectonic` even though [`apps/xtask/src/papers.rs`](../../apps/xtask/src/papers.rs) executes TeXLive `pdflatex` and `bibtex`.
3. **Contributor Walkthrough & GUI Tab Discovery Drift**: [`docs/architecture/interactive_tool_walkthrough.md`](../../docs/architecture/interactive_tool_walkthrough.md) taught non-existent `TheoryDescribable` methods (`theory_title`, `theory_equations`, and `&'static str` returns) inside `rust,ignore` fences and portrayed `InteractiveTool::step_simulation` as a per-frame `0.016s` loop rather than an offscreen GIF export hook, while [`math_explorer_gui/README.md`](../../math_explorer_gui/README.md) instructed contributors to manually edit `src/tabs/mod.rs` and non-existent `src/app.rs` contrary to [`math_explorer_gui/build.rs`](../../math_explorer_gui/build.rs).
4. **Incomplete Workspace Rustdoc & Narrow Fence Auditing**: `cargo doc --workspace --no-deps` in [`apps/xtask/src/gates.rs`](../../apps/xtask/src/gates.rs) and [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml) omitted `--all-features`, excluding all `7` feature-gated domain modules and `25` domain error enums from [`math_explorer`](../../math_explorer/src/lib.rs) rustdoc output, while `doc_audit` only scanned Rust fences for internal imports.

## Decision
1. **Preserve Minimal Default Core and Repair Active Guides**:
   - Keep `default = []` in [`math_explorer/Cargo.toml`](../../math_explorer/Cargo.toml) untouched, add explicit `--features` and `-p` flags to all documented Cargo CLI commands and consumer `[dependencies]` blocks, remove the orphaned `check_statrs.rs` file, catalog all `32` registered examples under their matching domain headings in [`math_explorer/examples/README.md`](../../math_explorer/examples/README.md), and align paper compilation documentation with TeXLive `pdflatex` and `bibtex`.
   - Update [`docs/architecture/interactive_tool_walkthrough.md`](../../docs/architecture/interactive_tool_walkthrough.md) and [`math_explorer_gui/README.md`](../../math_explorer_gui/README.md) to match [`TheoryDescribable`](../../crates/scientific_metadata/src/theory.rs), GIF-only `InteractiveTool::step_simulation`, and `build.rs` automatic `ExplorerTab` discovery.
2. **Enable Full-Feature Workspace Rustdoc Gates**:
   - Pass `--all-features` to `cargo doc --workspace --no-deps --all-features` (with `RUSTDOCFLAGS="-D warnings"`) in [`apps/xtask/src/gates.rs`](../../apps/xtask/src/gates.rs) and [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml) so generated docs render all `7` domain modules and all `26` error enums in `math_explorer`.
3. **Enforce Static Manifest, Catalog, CLI, TOML, and Trait Audits in `unified_verification`**:
   - Extend [`crates/unified_verification/src/doc_audit`](../../crates/unified_verification/src/doc_audit.rs) (without adding external dependencies) and wire staged documentation triggers into [`crates/unified_verification/src/batch.rs`](../../crates/unified_verification/src/batch.rs) to statically validate Markdown Cargo CLI targets/features, consumer `math_explorer` TOML feature declarations, `math_explorer/examples` manifest-to-catalog parity, TeXLive vs `Tectonic` alignment, GUI tab auto-discovery guidance, and `syn`-parsed `TheoryDescribable`, `InteractiveTool`, and `ExplorerTab` method signatures across Markdown fences (including `rust,ignore`).

## Consequences
- **Positive**: Evaluators, library consumers, and contributors receive copy-pasteable commands, complete `32`-example catalogs, full-feature API documentation, and accurate trait walkthroughs while `math_explorer` retains its `20`-package default dependency footprint.
- **Positive**: Both pre-commit (`lint-staged`) and CI (`check-docs` / `lint-all`) reject missing Cargo feature flags, catalog drift, `Tectonic` instructions, and stale guide trait signatures in milliseconds without spawning Cargo sub-builds.
