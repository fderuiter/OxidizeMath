# ADR 20261123: Workspace-Scoped `SharedSimulationBus`, Copy-on-Write CSR Topologies, and Zero-Allocation Graph Kernels

## Status
Accepted (extends [ADR 0009](0009-reusable-graph-layout-algorithms.md), [ADR 0035](0035-fermi-spatial-games-and-ising-droplet-brushes.md), [ADR 0039](0039-metric-agnostic-3d-tda-exact-z2-homology-and-chaos-mashup.md), and [ADR 0039](0039-network-epidemic-containment-primitives.md))

## Context
Multi-pane layouts (`SplitHorizontal`, `SplitVertical`, `QuadGrid`) allow side-by-side comparison across domain tabs, yet graph-dependent simulations (`NetworkMetricsTool`, `AlgorithmVisualizerTool`, `NetworkPropagationTool`, `NeuralNetworkVizTool`, `IsingModelTool`, and `ReplicatorDynamicsTool`) previously operated on isolated hardcoded sample graphs (wheel, 4x4 grid, seeded random geometric graph, 5-neuron ring, 100x100 square lattice, and well-mixed matrix ODEs). Editing nodes or weighted/directed edges in `GraphEditorTool` could not propagate into downstream physical, epidemiological, neural, or evolutionary game dynamics. Meanwhile, 3D chaotic landmark streaming from `AttractorPlotter` / `AttractorRunner` to `VietorisRipsTool` relied on process-global `OnceLock<Mutex<...>>` slots in `vietoris_rips/handoff.rs`, causing cross-talk whenever multiple `MathExplorerApp` instances ran concurrently in tests or separate viewports.

## Decision
1. **Zero-Allocation CSR Domain Kernels (`domain_physics`, `domain_applied`, `domain_epidemiology`, `domain_biology`)**:
   - Add [`GraphSpinSystem`](../../crates/domain_physics/src/physics/stat_mech/graph_ising.rs) over Compressed Sparse Row (CSR) `row_ptr` / `col_idx` / `weights` buffers supporting zero-allocation Metropolis-Hastings (`evolve`) and pairwise Fermi evolutionary game updates (`evolve_fermi_game`) verified over `1,000` steps under `VerifiedEngine::run_verified`.
   - Add [`GraphReplicatorFitness`](../../crates/domain_applied/src/applied/game_theory/evolutionary/graph_replicator.rs) implementing `FitnessStrategy` with the Ohtsuki-Nowak (2006) pair-approximation matrix $A_{\text{eff}} = A + B(A, k)$ (`DeathBirth`, `Imitation`, `BirthDeath`) and zero-allocation `DMatrix::mul_to` evaluation.
   - Add [`NetworkEpidemicModelBuilder::csr_adjacency`](../../crates/domain_epidemiology/src/epidemiology/networks/builder.rs) for validated CSR contact networks and [`step_csr_hodgkin_huxley_network`](../../crates/domain_biology/src/biology/neuroscience/synaptic_csr.rs) for zero-allocation CSR Hodgkin-Huxley synaptic conductance pulses using caller-owned `next_inputs` scratch slices.
2. **Workspace-Scoped `SharedSimulationBus` and `Link Topology` Sync (`math_explorer_gui`)**:
   - Attach an `Arc<RwLock<...>>`-backed [`SharedSimulationBus`](../../math_explorer_gui/src/app/sim_bus.rs) directly to [`MathExplorerApp`](../../math_explorer_gui/src/app/mod.rs) and install it into `egui::Context` temporary data on every frame alongside `ComparisonSyncConfig::link_topology` (exposed in `View -> Multi-Pane Sync -> Link Topology` and multi-pane chrome menus with polite `TwinSlotLiveRegion` announcements).
   - Publish immutable `Arc<SharedGraphTopology>` copy-on-write CSR snapshots (capped at `256` nodes and `2,048` edges with authored directed + symmetrized CSR arrays, viewport-normalized coordinates, and mean active degree $k$) from [`GraphEditorTool`](../../math_explorer_gui/src/tabs/graph_theory/graph_editor/bus_bridge.rs) whenever node/edge revision changes.
   - Subscribe `NetworkMetricsTool`, `AlgorithmVisualizerTool`, `NetworkPropagationTool`, `NeuralNetworkVizTool` (clamped at `32` neurons with a WCAG AA `"Clamped N -> 32 neurons"` warning pill), `IsingModelTool`, and `ReplicatorDynamicsTool` via a compact `#[serde(deny_unknown_fields)]` `TopologySource` (`SharedBus` default vs. per-pane `LocalPreset` opt-out) that keeps saved JSON and `#tab=...&state=...` share links inside `URL_JSON_BOUNDS` (`4 KiB`).
3. **Retire Process-Global `OnceLock` Landmark Handoffs**:
   - Route `AttractorPlotter` / `AttractorRunner` 3D landmark snapshots and live streams (`SharedPointCloud3D`, capped at `128` landmarks) through the workspace `SharedSimulationBus` in [`vietoris_rips/handoff.rs`](../../math_explorer_gui/src/tabs/geometry_topology/vietoris_rips/handoff.rs), eliminating every process-global `OnceLock<Mutex<...>>`.

## Consequences
- **Positive**: Sculpting a custom graph in `GraphEditorTool` updates network centrality, routing, heterogeneous $R_0$, spiking Hodgkin-Huxley circuits, CSR Ising/Fermi dynamics, and Ohtsuki-Nowak replicator trajectories within a single frame across `SplitHorizontal`, `SplitVertical`, and `QuadGrid`, while keeping `InteractiveTool` and `ExplorerTab` signatures untouched.
- **Positive**: Multiple `MathExplorerApp` workspaces run with strict bus isolation and zero cross-talk, and all hot-loop CSR solvers execute with zero heap allocations under `VerifiedAllocator`.
- **Neutral**: Shared CSR snapshots cap interactive topologies at `256` nodes (`32` Hodgkin-Huxley neurons) and `2,048` edges to guarantee 60 FPS frame budgets on native and `wasm32-unknown-unknown` targets; external multi-user network sync remains out of scope.
