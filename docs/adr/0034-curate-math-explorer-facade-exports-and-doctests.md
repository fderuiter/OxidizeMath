# ADR 0034: Curate `math_explorer` Facade Exports, Feature-Gated Dependency Graph, and Facade-Canonical Doctests

## Status
Accepted (extends [ADR 0004](0004-unified-verification-dependency-audit.md), [ADR 0013](0013-trait-level-runnable-doctests.md), and [ADR 0016](0016-standardize-crate-documentation-suite.md))

## Context
[`README.md`](../../README.md) and [`math_explorer/README.md`](../../math_explorer/README.md) establish [`math_explorer`](../../math_explorer/src/lib.rs) as the single public SDK facade over the internal domain crates (`pure_math` and `domain_*`). Three structural gaps prevented downstream Rust consumers from relying exclusively on `math_explorer`:
1. **Unconditional Heavy Dependencies Under `default = []`**: [`math_explorer/Cargo.toml`](../../math_explorer/Cargo.toml) declared `default = []` for lightweight embedding, yet listed `pure_math`, `nalgebra`, `oxidize_core`, `num-complex`, `petgraph`, and `rand` as unconditional dependencies while leaving `pure_math = []` as a no-op feature. Compiling `math_explorer --no-default-features` pulled `139` transitive packages instead of the `20`-package `math_commons` + `diagnostics` core.
2. **Incomplete Facade Re-Exports for Public Signatures and Domain Errors**: [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs) re-exported only `math_commons::math_kernel` and `diagnostics` alongside the domain modules, omitting sibling `math_commons` modules (`ast`, `constants`, `primitives`, `registry`, `wigner`), `pure_math::math_types` (`Integer`, `Float`, `Rational`), `oxidize_core::{mesh, rng}`, third-party public signature crates (`nalgebra`, `num_complex`, `petgraph`, `rand`), and all `26` crate-root error enums across `crates/*/src/error.rs` (including `MathError`, `AIError`, `BatteryError`, `EpidemiologyError`, `HodgkinHuxleyError`, `8` `pure_math` error enums, `6` `domain_applied` error enums, and `8` `domain_physics` error enums). Several public API signatures also referenced bound/alias types (`Complex64`, `IBig`, `ToPrimitive`, `statrs` distribution traits, `GenericAdam`) without local module re-exports.
3. **Internal-Crate Imports Across Doctests, Guides, and CLI Examples**: `204` rustdoc code imports across `pure_math` and `domain_*`, `14` active consumer Markdown guides (including [`docs/architecture/cera_framework.md`](../../docs/architecture/cera_framework.md)), and `15` CLI examples/benchmarks under `math_explorer/examples/` and `math_explorer/benches/` imported internal workspace crates (`use domain_*::...`, `use pure_math::...`, `use math_commons::...`) directly, causing copy-pasted snippets to fail with `E0432` in downstream crates depending only on `math_explorer`.

## Decision
1. **Feature-Gate Optional Dependencies for a Minimal `20`-Package Core**:
   - Mark `pure_math`, `nalgebra`, `oxidize_core`, `num-complex`, `petgraph`, and `rand` as `optional = true` in [`math_explorer/Cargo.toml`](../../math_explorer/Cargo.toml) and wire `pure_math` to `["dep:pure_math", "dep:nalgebra", "dep:num-complex", "dep:oxidize_core", "dep:petgraph", "dep:rand"]` with domain features transitively enabling `pure_math` and their respective `dep:domain_*` crates.
   - Preserve `default = []` so `cargo check -p math_explorer --no-default-features` compiles only `math_commons` and `diagnostics` (`20` packages total) while referencing every optional dependency in [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs) to satisfy `DependencyVisitor` without whitelist exemptions.
2. **Complete Public Facade Surface, `error`, and `prelude` Modules**:
   - Expand [`math_explorer/src/lib.rs`](../../math_explorer/src/lib.rs) to re-export `math_commons::{ast, constants, math_kernel, primitives, registry, wigner}`, `diagnostics`, and—when `pure_math` is enabled—`pure_math::math_types`, `oxidize_core::{mesh, rng}`, `nalgebra`, `num_complex`, `petgraph`, and `rand`.
   - Introduce [`math_explorer/src/error.rs`](../../math_explorer/src/error.rs) and [`math_explorer/src/prelude.rs`](../../math_explorer/src/prelude.rs) re-exporting `MathError`, `MathResult`, `NonNegativeFloat`, `PositiveFloat`, `UnitInterval`, `Diagnostic`, `Severity`, core containers, and all `26` crate error enums under their corresponding feature flags, alongside `pub use crate::error;` in every inner domain `mod.rs` (`ai::error`, `applied::error`, `biology::error`, `climate::error`, `epidemiology::error`, `physics::error`, `pure_math::error`) and `BatteryError` in [`crates/domain_applied/src/applied/battery_degradation/mod.rs`](../../crates/domain_applied/src/applied/battery_degradation/mod.rs).
   - Re-export public signature bound/alias types (`Complex64` in `math_commons::ast`, `IBig` in `pure_math::math_types`, `ToPrimitive` in `pure_math::statistics::markov`, `statrs` distribution traits in `applied::game_theory::mechanism_design`, and `GenericAdam` in `ai::optimization`).
3. **Facade-Canonical Doctests, Consumer Guides, and Automated Governance**:
   - Add `#[doc(hidden)] pub mod __doctest_facade` shims in [`crates/pure_math/src/lib.rs`](../../crates/pure_math/src/lib.rs) and `crates/domain_*/src/lib.rs` mirroring the `math_explorer` namespace so rustdoc examples and `markdown_tests` compile via `# use <crate>::__doctest_facade as math_explorer;` while rendering clean `use math_explorer::...` imports to readers.
   - Migrate all domain rustdoc examples, active consumer Markdown guides, and `math_explorer` examples/benchmarks to `math_explorer` paths.
   - Enforce regression protection via [`crates/unified_verification/src/api_drift/facade.rs`](../../crates/unified_verification/src/api_drift/facade.rs) (auditing `math_explorer::error` coverage of all `crates/*/src/error.rs` public enums, inner `<domain>::error` re-exports, and public signature type reachability), [`crates/unified_verification/src/doc_audit/facade_imports.rs`](../../crates/unified_verification/src/doc_audit/facade_imports.rs) (rejecting visible `domain_*::` / `pure_math::` imports in active guides, domain rustdoc fences, and facade examples/benches), and [`math_explorer/tests/facade_exports.rs`](../../math_explorer/tests/facade_exports.rs).

## Consequences
- **Positive**: `math_explorer` with `default = []` compiles a `20`-package core (`85.6%` fewer packages than `139`), while enabling domain features exposes every error enum, validated primitive, container, and bound trait required by public signatures without direct dependencies on internal workspace crates.
- **Positive**: Every visible Rust snippet in rendered `cargo doc` output, active Markdown documentation, and `math_explorer/examples/` compiles directly against `math_explorer`, continuously guarded by `check-api-drift`, `check-docs`, and `xtask test-features`.
- **Neutral**: Historical architectural decision records under `docs/adr/` remain immutable records of past crate-internal changes, and internal crate boundaries (`pure_math`, `domain_*`) remain decoupled for parallel workspace compilation.
