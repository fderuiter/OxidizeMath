# ADR 20261123: Feature-Gate Core AST Tools and Unify Workspace Crates

## Status
Accepted (extends [ADR 0003](0003-traceability-refactoring.md), [ADR 0007](0007-purge-obsolete-scripts-and-dependencies.md), and [ADR 0032](0032-precomputed-traceability-manifest-and-wasm-vfs-subpaths.md))

## Context
Two dependency-graph issues inflated compile times, transitive crate counts, and WebAssembly target graphs across the workspace:
1. **Unconditional AST and TOML Tooling in `oxidize_core`**: [`crates/oxidize_core/Cargo.toml`](../../crates/oxidize_core/Cargo.toml) unconditionally compiled `syn`, `quote`, `proc-macro2`, `async-recursion`, `toml`, and `futures`. Every downstream scientific crate (`pure_math`, `domain_*`, `math_explorer`) and `wasm32-unknown-unknown` target build of `math_explorer_gui` pulled in Rust parser/AST machinery even though WebAssembly uses precomputed `./traceability_manifest.json` snapshots and domain crates only require deterministic RNG, mesh/boundary primitives, and `verify_module_registered` checks.
2. **Duplicate Linear-Algebra and Compression Versions in `Cargo.lock`**: `statrs 0.17` pulled in `nalgebra 0.32.6`, `nalgebra-macros 0.2.2`, and `simba 0.8.1` alongside workspace `nalgebra 0.34.2` and `simba 0.9.1`, solely for `MultivariateNormal` covariance validation in [`crates/pure_math/src/pure_math/statistics/copula/gaussian.rs`](../../crates/pure_math/src/pure_math/statistics/copula/gaussian.rs). Meanwhile, `flate2 1.1.11` introduced `miniz_oxide 0.9.1` alongside `miniz_oxide 0.8.9`, and `png` / `arboard` versions were declared inline rather than centralized in [`Cargo.toml`](../../Cargo.toml).

## Decision
1. **Optional `ast-analysis` Feature Gate and Iterative Module Traversal in `oxidize_core`**:
   - Gate `syn`, `quote`, `proc-macro2`, `toml`, and `futures` behind an optional `ast-analysis` feature in [`crates/oxidize_core/Cargo.toml`](../../crates/oxidize_core/Cargo.toml), and mark `traceability_cli` with `required-features = ["ast-analysis"]`.
   - Replace `#[async_recursion::async_recursion(?Send)]` on `TraceabilityEngine::parse_module_tree` in [`crates/oxidize_core/src/traceability.rs`](../../crates/oxidize_core/src/traceability.rs) with an explicit iterative `Vec<String>` stack, removing `async-recursion` from the workspace entirely.
   - Keep `TraceabilityReport`, `TraceabilityManifestPayload`, `VerificationCertificate`, and `TraceabilityEngine` (`new`, `extract_citations`, and pure-`std` `verify_module_registered`) unconditional in [`crates/oxidize_core/src/traceability.rs`](../../crates/oxidize_core/src/traceability.rs) and [`crates/oxidize_core/src/traceability/analysis.rs`](../../crates/oxidize_core/src/traceability/analysis.rs), while routing `parse_workspace_members` in [`crates/oxidize_core/src/workspace.rs`](../../crates/oxidize_core/src/workspace.rs) through `parse_workspace_members_std` when `ast-analysis` is inactive.
   - Enable `oxidize_core` `features = ["ast-analysis"]` only in [`crates/unified_verification/Cargo.toml`](../../crates/unified_verification/Cargo.toml) and the host-only (`cfg(not(target_arch = "wasm32"))` and `[build-dependencies]`) sections of [`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml), moving `futures` out of `math_explorer_gui`'s unconditional `[dependencies]`.
2. **Unify `statrs`, `nalgebra`, `png`, `arboard`, and `flate2`**:
   - Upgrade `statrs` in [`Cargo.toml`](../../Cargo.toml) to `0.18.0` with `default-features = false, features = ["rand"]` so univariate distributions and `rand` sampling traits remain available without `nalgebra 0.32`.
   - Replace `statrs::distribution::MultivariateNormal` covariance checks in [`crates/pure_math/src/pure_math/statistics/copula/gaussian.rs`](../../crates/pure_math/src/pure_math/statistics/copula/gaussian.rs) with Cholesky decomposition (`cov.cholesky()`) on workspace `nalgebra 0.34`.
   - Centralize `png` and `arboard` in `[workspace.dependencies]` of [`Cargo.toml`](../../Cargo.toml) for [`egui_plot/Cargo.toml`](../../egui_plot/Cargo.toml) and [`math_explorer_gui/Cargo.toml`](../../math_explorer_gui/Cargo.toml), and select `flate2 1.1.9` in `Cargo.lock` to unify on a single `miniz_oxide` release.

## Consequences
- **Positive**: `oxidize_core` and `math_explorer_gui` on `wasm32-unknown-unknown`, as well as `pure_math`, `domain_*`, and `math_explorer`, compile without `syn`, `quote`, `proc-macro2`, `async-recursion`, `toml`, `winnow`, or `futures` in `oxidize_core`, while preserving all public item paths and signatures in [`crates/unified_verification/api_baseline.json`](../../crates/unified_verification/api_baseline.json).
- **Positive**: `Cargo.lock` removes `async-recursion` from all workspace crates (retaining it only transitively under Linux `eframe -> accesskit_unix -> zbus`) and eliminates `nalgebra 0.32.6`, `nalgebra-macros 0.2.2`, `simba 0.8.1`, and `miniz_oxide 0.9.1`, unifying the workspace on single active versions of `nalgebra`, `simba`, and `miniz_oxide`.
- **Neutral**: Host-side precomputed manifest generation in [`math_explorer_gui/build_snapshot.rs`](../../math_explorer_gui/build_snapshot.rs) and static verification in `unified_verification` continue to run full AST traceability scans via `oxidize_core/ast-analysis`.
