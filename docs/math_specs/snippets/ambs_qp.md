Checks prime-power modularity congruences for odd-square quasiperfect candidates satisfying $\sigma(n) = 2n + 1$.

Reference: Hagis & Cohen (1982), DOI: 10.1017/S1446788700018401;
[`docs/math_specs/pure_math.md`](../pure_math.md).

# Stability
Uses exact arbitrary-precision modular arithmetic via [`Integer`](crate::math_types::Integer) with zero floating-point rounding error.

# Domain of Validity
Valid for positive odd prime-power divisor-sum prefixes and positive integer moduli parsed in base 10.
