Recovery Steps

Enable Hardware Acceleration & WebGL

Google Chrome / Microsoft Edge / Brave

  1. Open Settings (⋮ → Settings).
  2. Navigate to System (or System and performance).
  3. Toggle on Use graphics acceleration when available (or Use hardware acceleration).
  4. Relaunch your browser and refresh this page.

Mozilla Firefox

  1. Open Settings → General.
  2. Under Performance, uncheck Use recommended performance settings.
  3. Check Use hardware acceleration when available.
  4. Restart Firefox and refresh this page.

Apple Safari

  1. Open Safari Settings → Advanced → check Show features for web developers.
  2. In the Develop menu, open Experimental Features and verify WebGL is enabled.
Additional checks: Verify your graphics drivers are current, test WebGL compatibility at get.webgl.org, and ensure browser extensions or privacy modes are not blocking WebGL contexts.
